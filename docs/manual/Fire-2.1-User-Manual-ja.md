## 01. はじめに

本書は、拡張モジュレーションシステム、Dynamic EQ、パラレルチェーン、サンプルのインポート/エクスポート、統一された OTT 表示を備えた**開発中の Fire 2.1.0** を説明します。製品ソース **9ea20d2** に基づき、**2026 年 10 月 24 日**に作成しました。ホストに読み込まれているバージョンは **Menu > Settings** で確認してください。一般公開されているダウンロード版では、一部の機能がまだ利用できない場合があります。

本書の例には、現在のプラグインとデモ用に生成した音声を使って取得した実際の画面を掲載しています。スクリーンショットの設定は説明用であり、調整済みのプリセットや必須の設定値ではありません。主に Ink を使用し、ハードウェア風の表示には Vintage を使用しています。外観を変更しても音は変わりません。

### インストールして Fire を読み込む

Fire は、対応するホストで利用できるプラグイン形式で提供されます。DAW が対応している形式を選んでください。Audio Unit は macOS 用の形式です。コピーする際は、プラグインバンドルの内部構成を変更しないでください。

| プラットフォーム | 形式 | 一般的なインストール先 |
| --- | --- | --- |
| macOS | Audio Unit | `~/Library/Audio/Plug-Ins/Components/` |
| macOS | VST3 | `~/Library/Audio/Plug-Ins/VST3/` |
| macOS | CLAP | `~/Library/Audio/Plug-Ins/CLAP/` |
| Windows | VST3 | `C:\Program Files\Common Files\VST3\` |
| Windows | CLAP | `C:\Program Files\Common Files\CLAP\` |
| Linux | VST3 | `~/.vst3/` |
| Linux | CLAP | `~/.clap/` |

1. [Fire の公式リリース](https://github.com/jerryuhoo/Fire/releases)から適切なビルドをダウンロードします。パッケージに記載された OS とプロセッサーアーキテクチャを確認してください。ローカルの開発ビルドには、ビルドに使用したマシンのアーキテクチャしか含まれない場合があります。
2. 既存のインストールを置き換える前に DAW を終了します。必要な形式を対応するプラグインフォルダーにコピーします。ユーザーフォルダーが存在しなければ作成してください。Windows のシステムフォルダーには管理者権限が必要な場合があります。
3. DAW を再起動し、必要に応じてプラグインを再スキャンします。**オーディオエフェクト**として **Fire** を探してください。メーカー別に表示するホストでは、Blue Wings Music の項目にあります。
4. オーディオトラック、ソフトウェア音源の後段、またはオーディオバスに挿入します。そのトラックが音を聴ける出力先に接続されていることを確認します。
5. Settings を開き、読み込まれたバージョンを確認します。古いバージョンが表示された場合は、もう一度コピーする前に、ホストが選んだ形式と検索対象フォルダーを調べてください。

macOS では、ダウンロードした開発ビルドやアドホック署名のビルドに対して、システムのセキュリティ承認が必要になる場合があります。リリースの署名に関する説明と OS の案内に従ってください。バンドルの検証に失敗した場合は、公式版を再取得してください。内部ファイルを変更すると署名が無効になります。

### 5 分で始める最初のセッション

Fire はオーディオエフェクトです。入力音声が必要なため、ソフトウェア音源の後段、オーディオトラック、または音声を受け取るバスに挿入してください。MIDI ノートだけで楽器の音を生成するものではありません。ホストから MIDI を送れば、モジュレーションの制御に利用できます。

1. 小さな音と大きな音の両方を含む短いフレーズを再生するか、ループさせます。聴きやすいモニターレベルから始めてください。
2. Fire のヘッダーにあるサウンド名をクリックします。全面表示の **Sound Library** が開きます。**Analog Drive** を選び、**Valve Bloom**、**Tweed Touch**、**Iron Program Bus**、**Tape Studio Print** などのシーンをクリックします。1 回のクリックでサウンドが読み込まれ、ライブラリーは開いたままになります。
3. **Back to Reactor** をクリックします。Fire はそのシーンに対応する Shape ページを選びます。色付けを行う段を Master Lab に配置するシーンもあれば、1 つ以上のバンドを使うシーンもあります。
4. ワークスペースのタブ付近にある 4 つのマクロノブを操作します。Analog Drive のシーンでは、**Drive**、**Tone**、**Output trim**、**Dry blend** です。名前はそのシーンでの割り当てを表しており、4 つの追加エフェクトプロセッサーではありません。
5. **Match** をオンにして、ループを約 3 秒間再生します。補正値が表示されるまで待ってください。出力音量が大きくなったことだけに影響されず、音色を比較しやすくなります。
6. **Copy** を押し、**A/B** を切り替えて、もう一方のサウンドメモリーを編集します。Match の数値/Learn コントロールをクリックし、同じフレーズを再生して新しい補正値を学習させます。A/B を切り替えて比較してください。
7. **Save** をクリックし、結果をユーザープリセットとして保存します。プロジェクト固有の比較設定、ロック、ホストのセッション全体も保持したい場合は、DAW のプロジェクトも保存してください。

![Ink の Fire。ヘッダーのコントロール、3 つの周波数バンド、ワークスペースのタブ、マクロ、選択中の Band チェーン。](images/01-overview-ink.png)

## 02. インターフェースとスペクトラム

ヘッダーには、A/B 比較、Copy、Match、プリセット名と前後の選択ボタン、Save、アプリケーションメニュー、HQ があります。上部のスペクトラムには入力音声と処理後の音声が表示され、周波数バンドを編集できます。その下にある 3 つのワークスペースに、各種コントロールが整理されています。

| ワークスペース | 用途 |
| --- | --- |
| **Band Lab** | 現在選択している周波数バンドのチェーンと、その Output および Mix を編集します。 |
| **Mod Forge** | LFO の波形、再生動作、MIDI 設定を編集し、モジュレーションマトリクスを開きます。 |
| **Master Lab** | 各バンドを合成した出力に対して処理を行うチェーンを編集します。 |

各オーディオワークスペースには **CHAIN** の一覧があります。行をクリックすると、そのモジュールが開きます。処理モジュールの行の横にある小さなスイッチで、有効/無効を切り替えます。見た目はスキンによって異なります。標準の Band Shape には、06 章で説明する Serial モードの互換動作に関する例外があります。行にマウスを重ねるかフォーカスを移すと、削除用の **-** が表示されます。**+** でモジュールを追加し、**...** でチェーンのコピー、貼り付け、ファイル操作を行います。**Stereo**、**Mid**、**Side** のいずれかを表示する小さなボタンで Routing を開きます。

4 つのマクロコントロールは、ワークスペースのタブの横からすぐに操作できます。値と名前はサウンドに保存されます。名前を変更するにはマクロ名をダブルクリックし、Enter で確定、Escape でキャンセルします。名前は最大 32 文字です。空にすると「Macro 1」などの既定名に戻ります。マクロノブをダブルクリックすると値はゼロに戻ります。名前を変更しても、DAW オートメーション上の識別子は変わりません。

グラフの **VIEW** メニューがある場合、**Auto** は選択したモジュールに応じた表示を選びます。Waveform、Transfer、Meters、Stereo を明示的に選ぶと、同じ信号を別の観点から確認できます。例えば、ディストーションの調整には伝達特性グラフが役立ち、音量変化の判断には Meters が便利です。OTT には独自の **LIFT / PRESS** 表示があり、Band と Master に個別に追加した OTT でも利用できます。拡大アイコンでグラフを広げ、復元アイコンで元のコントロール配置に戻します。

### スペクトラムの操作とバンドの編集

スペクトラム内のバンドの下側をクリックすると、Band Lab で編集するバンドとして選択されます。スペクトラム上部の帯を目的の周波数でクリックするとクロスオーバーを作成でき、合計 4 バンドまで分割できます。クロスオーバーの線をドラッグするか、周波数表示を編集して周波数を変更します。バンドの電源と **S** コントロールで、各バンドのバイパスとソロを切り替えます。バンドの削除コントロールはそのバンドを削除しますが、少なくとも 1 バンドは残す必要があります。

スペクトラムの背景自体にフォーカスがあるときは、**Return** または **+** で選択中のバンドを分割し、**Delete** または **Backspace** で削除します。周波数フィールドなどの子コントロールにフォーカスがある間は、この操作は適用されません。

コンパクトなスペクトラムツールバーには、チャンネル選択、拡大/復元、折りたたみがまとめられています。操作していないときは半透明になり、マウスを重ねたとき、キーボードフォーカスがあるとき、またはメニューを開いているときには通常の濃さで表示されます。スペクトラムを折りたたむと、3 つすべてのワークスペースで操作領域が広がります。ワークスペースのコントロール横にある小さな復元ボタンで再表示できます。

<!-- table:keep -->
| スペクトラムモード | 測定する内容 |
| --- | --- |
| **Left / Right** | 片方の入出力チャンネル。 |
| **Stereo** | 両チャンネルの合成エネルギー。左右が逆極性でも打ち消されません。 |
| **Mono** | `(L + R) / 2`。モノラル合成時の打ち消しも反映されます。 |
| **Side** | `(L - R) / 2`。ステレオの差成分を表示します。 |

この選択で変わるのは表示だけです。音声処理を変えたい場合は、チェーンの Routing でチャンネルを選んでください。左右が同じ音声は Side では消え、逆極性の音声は Mono では消えます。これは正常な動作です。片方のチャンネルだけに信号がある場合、Stereo はそのチャンネル単独の表示より約 3 dB 低く、Mono/Side は約 6 dB 低くなります。

### コントロールの読み方

ノブの値は常時表示されるとは限らず、ドラッグ中、フォーカス中、編集時に表示されることがあります。ツールチップにはコントロールの説明が表示されます。モジュレーションを割り当てると、ソースの色を使った範囲と動くマーカーが追加されます。基準値とモジュレーション後の値は別のものです。グラフの全画面ボタンを押すと選択中の表示が拡大し、その下のコントロールが一時的に隠れます。縮小すると元のコントロールが戻ります。

エディターは縦横比 2:1 を維持し、1000 x 500 から 2000 x 1000 までのサイズに対応します。隅をドラッグして変更してください。大きいウィンドウでは、パラメーター名やグラフの細部により広い表示領域を確保できます。

## 03. プリセットと Sound Library

プリセット名をクリックすると Sound Library が開きます。左側にコレクション、右側に個々のサウンドが並びます。ファクトリーカタログには 236 のシーンがあります。Vocals、Synths、Drums、Bass、Guitar、Keys、Spaces、Lo-Fi、Rhythm、Effects に各 20、Analog Drive に 36 が収録されています。ユーザーサウンドは **User** に表示されます。ファクトリーサウンドは音作りの出発点です。編集したシーンはユーザープリセットとして保存してください。

検索欄に入力すると、サウンドの説明情報に基づいて絞り込めます。行をクリックすると、その場で読み込んで試聴できます。行のダブルクリック、**Back to Reactor** のクリック、または Escape で処理画面に戻ります。検索欄にフォーカスがないときは、Up/Down で前後のサウンドを試聴できます。現在のサウンドはハイライトされたままになります。ヘッダーの前後の矢印でもプリセットを順に切り替えられます。

作業中は、現在のコレクション、検索内容、スクロール位置が保持されます。**Recent** には最近試聴したサウンドが最大 24 件残ります。**Locate current** は検索を解除し、再生中のプリセットをそのコレクション内に表示します。最近の履歴と閲覧位置はセッション中の利便性のためのもので、サウンドファイルや DAW プロジェクトには含まれません。

### お気に入り、非表示、復元

サウンドの星印をクリックすると、**Favourites** への登録と解除を切り替えられます。お気に入りはローカルライブラリーに記憶されます。プリセットの削除コントロールは、サウンドの種類によって動作が異なります。

| サウンドの種類 | 削除時の動作 | 復元 |
| --- | --- | --- |
| ユーザープリセット | ファイルを Fire の **Recycle Bin** に移動します。 | 元のコレクションに戻します。 |
| ファクトリープリセット | ファクトリー項目を非表示にします。 | Recycle Bin から非表示のサウンドを復元します。 |

復元してもサウンドは読み込まれず、既存のユーザーファイルも上書きされません。したがって、項目の削除は、現在再生中のサウンドの初期化とは別の操作です。初期状態に戻したい場合は、**Menu > Init** を使用してください。

### タグと説明

![プリセットの詳細画面では、説明用のタグとノートを編集できます。ファクトリー項目の編集はローカルのメタデータ上書きとして保存されます。](images/21-preset-details.png)

サウンドを選び、鉛筆形の詳細編集アイコンをクリックすると、タグと説明を編集できます。タグはカンマで区切ります。タグ自体にカンマを含める場合は、そのタグを引用符で囲んでください。タグは最大 16 個、各タグは 32 文字、説明は最大 2,048 文字まで入力できます。

ユーザープリセットでは、この情報は `.fire` ファイルに保存されます。詳細を編集しても、音声設定とフリーズした Granular の録音は保持されます。プリセットを上書き保存するとノートが保持され、新しいバージョンとして保存すると選択中のサウンドのノートが引き継がれます。ファクトリー項目の編集は個人用ライブラリーの上書き情報です。**Restore original** で付属のタグと説明に戻せます。アーカイブされたユーザープリセットは、復元してから詳細を編集してください。詳細エディターを開いている間にファイルが変更された場合は、保存前に開き直してください。

### プリセットを切り替えても選んだ値を保持する

> 同じ名前のコントロールを持つモジュールが複数ある場合は、対象のノブのコンテキストメニューから特定の値をロックする方法が確実です。ロックはサウンド読み込み時の基準値を保持します。入力音声をフリーズしたり、モジュレーションを無効にしたり、モジュール全体を自動的にロックしたりするものではありません。

プリセットのパラメーターロックは、プラグイン全体のプリセットを読み込むときや順に切り替えるときに、選択した**ノブの基準値**を維持します。例えば、特定の Output や Mix の値を保持したままサウンドを試聴する場合に便利です。

1. 対応するノブを右クリックし、**Keep value when loading presets** を選びます。**Menu > Preset parameter locks...** からも開けます。
2. ロックウィンドウでパラメーターを検索し、保持したい項目を有効にします。**Locked only** は現在のロックだけを表示し、**Unlock all** はすべてを解除します。
3. 別のプリセットを読み込みます。ロックした基準値は保持されます。保存済みプリセットとは異なる状態になるため、通常の変更済みマーカー `*` が表示される場合があります。

![プリセットロックの管理画面には利用可能なコントロールが並びます。目的のノブを直接右クリックすると、同じモジュールが複数ある場合でも対象を明確にできます。](images/20-preset-locks.png)

ロックしても、手動編集、ホストオートメーション、モジュレーションは無効になりません。読み込むプリセットのモジュレーションルーティングとソース定義は適用されるため、ロックした基準値もモジュレーションによって動きます。バンド数、クロスオーバー、モジュールの有無/順序、ルーティングモード、ブランチ割り当てといった構造的な設定はロックできません。ロック設定はインスタンスのプロジェクト状態に保存され、`.fire` サウンドには含まれません。A/B 切り替え、Undo/Redo、プロジェクト復元では、プリセット閲覧用のロックを適用せず、完全な状態を復元します。

### 保存先ごとに保持される内容

| 保存先 | 主な内容 |
| --- | --- |
| プラグイン全体の `.fire` プリセット | サウンドのパラメーター、チェーン、ソースと割り当て、マクロ名、フリーズした Granular 音声、ユーザーノート。 |
| `.firechain` プリセット | 1 つのチェーンのモジュール/設定、チャンネルとパラレルルーティング。必要に応じて、そのチェーンを宛先とするモジュレーションルーティング。 |
| DAW プロジェクト | A/B の Match 情報やプリセットロック設定を含む、インスタンス全体の状態。 |
| ローカル設定/ライブラリー | スキン、お気に入り、非表示のファクトリー項目、ファクトリーメタデータの上書き。 |
| 現在のエディターセッション | ライブラリーの検索/スクロール/最近の閲覧状態、一時的な検出信号の試聴。 |

**Menu > Open Preset Folder** でライブラリーの場所を確認できます。Fire の外でサウンドファイルを整理した後は、**Rescan Preset Folder** を実行してください。自作プリセットとプロジェクトのバックアップを保管しておきましょう。

## 04. A/B、ラウドネス Match、編集履歴

ヘッダーの **A/B** は、完全なサウンドを保持する 2 つのメモリーを切り替えます。**Copy** は現在の側をもう一方へコピーします。これは、パラレルエフェクトチェーン内の **A/B ブランチ**とは別の機能です。サウンドメモリーは状態全体を比較し、ブランチは音声を同時に処理します。

同じ音量で比較するには、両方のメモリーで同じ代表的なフレーズをループ再生します。**Match** を有効にして、現在の側を約 3 秒間学習させます。A/B を切り替え、もう一方も学習させてください。それぞれの側に個別の固定 dB 補正値が保持されます。Copy はこの補正値もコピーします。

数値/Learn コントロールをクリックすると再測定できます。測定中にクリックするとキャンセルします。Match をオフにすると補正前のレベルを聴けます。Match は Output やそのオートメーションを変更しません。ホストのバイパス時にはバイパス信号を通し、学習を一時停止します。

**Play audio** は、測定に必要な入力と出力が十分に得られなかったことを示します。以前の有効な結果は保持されます。**LIMIT** は必要な補正が利用可能な ±18 dB を超えることを示します。Match は短時間の試聴比較用ツールであり、積算 LUFS メーターではありません。編集中も補正値は固定されるため、大きく変更した後は再学習してください。サウンドプリセットを読み込むと、その側の測定値が消去され、Match が有効のままなら再学習します。Match と学習済みゲインは、`.fire` ファイルとは別にプロジェクトへ保存されます。

### 元に戻す/やり直す

**Menu > Undo / Redo**、**Cmd/Ctrl-Z**、**Cmd/Ctrl-Shift-Z**、または **Ctrl-Y** を使用します。Undo は通常のノブ操作や、モジュールの複製、チェーンの置き換えなどを、意味のある編集単位にまとめます。LFO 波形、ルーティング、EQ ポイント、フリーズ素材の変更にも対応します。エディターを閉じて開き直しても履歴は残りますが、DAW プロジェクトを読み込むと新しい履歴になります。オーディオスレッドのオートメーションは、パラメーター更新ごとに Undo 項目を作成しません。Fire は 64 MiB のスナップショット容量内で最大 100 回の編集を保持します。Undo によって現在のエディターサイズが変わることはありません。

## 05. チェーン、パラレルルーティング、Mid/Side

Fire は入力を 1 つから 4 つの周波数領域に分割します。選択した Band チェーンはその領域を処理し、各バンドの出力を合成した後、Master チェーンで処理します。

```text
入力 -> 周波数分割 -> Band チェーン -> 再合成 -> Master チェーン -> 出力
                         |  |  |  |
                       最大 4 バンド
```

Band Lab と Master Lab は、Drive、Shape、Compressor、OTT、Stereo、EQ、Lo-Fi、Chorus、Flanger、Phaser、Delay、Reverb、Granular、Chord Resonator を共通で利用できます。標準の行も追加モジュールと同様に削除し、再追加できます。各チェーンには、独立した追加インサートスロットを最大 8 つ使用できます。Analysis は削除可能な Master の表示ページであり、音声処理は行いません。

**+** をクリックしてモジュールを選びます。行をクリックすると編集できます。行の名前または本体をドラッグすると順序を変更でき、挿入位置の線で新しい位置を確認できます。一覧の端付近で保持するとスクロールし、隠れている行に移動できます。離すと確定します。Escape、一覧の外へのドロップ、ワークスペース/バンドの切り替えでドラッグをキャンセルします。並べ替えても、そのモジュールのパラメーターとルーティングは保持されます。オーディオモジュールは表示順に処理し、Band の Output/Mix はチェーンの後に適用されます。

### Serial、Parallel、Mid、Side

![Routing パネルではチャンネル、Serial/Parallel モード、ブランチ割り当て、Blend をまとめて設定します。各ブランチは既存のチェーンモジュールを使用します。](images/13-routing-detail.png)

CHAIN 横のコンパクトな Stereo/Mid/Side ボタンをクリックし、Routing を開きます。

| コントロール | 動作 |
| --- | --- |
| **Serial** | モジュールを順番に処理します。 |
| **Parallel A/B** | 両ブランチに同じチェーン入力を送り、その出力をブレンドします。 |
| **To A / To B** | モジュールをもう一方のブランチに移動します。行のメニューにも **Move to Branch A/B** があります。 |
| **Up / Down** | ブランチ内のモジュール順序を変更します。 |
| **Blend** | Branch B の割合。0% は A のみ、100% は B のみです。 |
| **Stereo** | ステレオ信号を処理します。 |
| **Mid** | 中央成分を処理し、元の Side 成分は保持します。 |
| **Side** | 差成分を処理し、元の Mid 成分は保持します。 |

パラレルブランチは既存のモジュールスロットを共有します。独立した 8 スロットのラックがもう 1 つ作られるわけではありません。空のブランチは入力をそのまま通します。ブレンドは線形のため、両ブランチが同一ならゲインは変わりません。Blend が端の値でも両ブランチは動作し続け、ディレイ/リバーブの履歴を最新に保ちます。ブランチは遅延を揃えてから合成され、その対象範囲の Output/Mix は合成後に適用されます。Mid/Side 処理は、両ブランチを含むチェーン全体を包みます。

パラレルコンプレッションでは、B に Compressor または OTT を置き、A を空にします。細部と密度が素材に合うまで、Blend を 0% から上げてください。異なる色付けを混ぜるには、A と B に別々の Shape モジュールを置きます。Blend は通常のモジュレーションとホストオートメーションに対応し、マトリクスでは **Routing / Blend** にあります。Serial モードでも、後で使えるようブランチ割り当てと Blend を記憶します。構造的なルーティングとブランチ割り当てはホストオートメーションに対応しますが、内部モジュレーションの宛先にはできません。

Mid または Side を選んだ場合、対応する対象範囲の出力コントロールはその成分に作用します。ステレオエフェクトの出力は選んだ成分へ平均化して戻されるため、処理していない成分へ音が漏れません。モノラル入力では、Mid は Stereo と同様に動作し、Side は同じレイテンシーを保って通過します。アナライザーで **Side** を選ぶ操作は差成分を表示するだけで、この処理モードを有効にはしません。

### モジュールをコピーする

モジュールの行を右クリックするか、行にフォーカスを移して **Shift+F10** を押します。

- **Copy settings** は、宛先側のモジュレーションルーティングを含めずにモジュールをコピーします。
- **Copy with routing** は、そのルーティングも含めます。
- **Duplicate settings** は、設定のみの複製をコピー元の直後に挿入します。
- **Paste ... after** は、選んだ行の後にコピーしたモジュールを挿入します。空のチェーンに貼り付けるには、**+** 内のコピー済みモジュール項目を使います。

コピーしたモジュールはブランチ割り当てを保持しますが、貼り付け先のルーティングモード、Blend、Stereo/Mid/Side モードは変更しません。モジュールとチェーンのクリップボードは別です。同じプロセス内で同じプラグイン形式の Fire インスタンス間で共有できます。

### チェーン全体をコピー/保存する

チェーンの **...** メニューを開きます。**Copy chain settings** または **Copy chain with routing** で、オーディオモジュールを順番ごとコピーします。**Paste chain** は貼り付け先のチェーンだけを置き換えます。他のバンド、Master、クロスオーバー、Output/Mix、グローバルなモジュレーションソースは保持されます。空のチェーンをコピーすると、別のチェーンのオーディオモジュールを消去できます。Analysis はコピーに含まれません。

設定のみの `.firechain` には **Save chain preset...** を、割り当ても含めるには **Save chain preset with routing...** を使用します。**Load chain preset - replace...** は、ファイルの内容で現在のチェーンを置き換えます。チェーンファイルはプリセットフォルダー内の **Chains** フォルダーを使用します。チャンネル/パラレルルーティングのほか、モデル、EQ ポイント、フリーズ音声などのモジュールデータが含まれます。

「With routing」は、宛先への割り当て、範囲、カーブ、深さを制御するマクロの割り当てをコピーします。使用される LFO、エンベロープ、マクロ、MIDI CC 設定は貼り付け先インスタンスの現在のもので、それらのソース定義は上書きしません。元のサウンド全体が必要な場合は、プラグイン全体のプリセットを使ってください。

Fire は貼り付け先を変更する前に、内容全体を互換性のあるスロットに収められるか確認します。一部の標準モジュールには、対応する内部の標準構成が必要です。標準の Master Lo-Fi は別のエンジンを使い、Legacy Link を使う Drive には標準 Drive スロット、または Drive Comp への変換が必要な場合があります。必要な設定やルーティングを保持できない場合は理由を表示し、貼り付け先を変更しません。

### 順序と 3 段階の Mix

順序は音色とダイナミクスの両方に影響します。ディストーション前の EQ は、どの周波数が強く歪むかを決めます。後の EQ は、すでに生成された倍音を整えます。ディストーション前のコンプレッサーは入力レベルを安定させ、後のコンプレッサーは歪んだ結果を制御します。ディストーション前の Delay では各反復音が歪みに作用し、後の Delay では歪んだ音を繰り返します。

モジュールの **Mix** は、通常、その入力とそのモジュールの処理済み信号を混ぜます。標準の隣接した Band Drive > Shape 経路では、Shape Mix は Drive を含む結合されたディストーション段全体をブレンドします。**Band Mix** はバンドのチェーン全体とそのバンドのドライ信号を混ぜ、グローバルの **Mix** は全体のエフェクトとドライ経路を混ぜます。これらは重ねて作用するため、モジュールの Mix と Band Mix の両方を低くすると、効果は非常に控えめになります。**Output** は歪みの量ではなくレベルを制御します。出力トリムで音量を揃え、チェーンを変更した後にも見直してください。

> 完全なドライのパラレルブランチを基準として使うには、先にその処理モジュールを移動するか削除してください。Routing の例の画面では、A にモジュールがあり、空のドライブランチではありません。Serial モードの標準 Band Shape には互換動作の経路が残ります。06 章を参照してください。

## 06. Drive と Shape

Drive と Shape は、Fire のディストーション操作の中心です。**Drive** は非線形処理段に入るレベルを上げます。**Shape** は伝達カーブやアナログの色付けを選び、その非対称性を調整します。標準のバンドチェーンでは、隣り合う Drive > Shape が結合された処理経路を使用します。離して配置すると別々の段になり、間に挿入したエフェクトが Shape に届く信号に影響します。

![Vintage の Warm Triode。ハードウェアのイラスト、Shape のローカルコントロール、選択中のバンドを表示しています。真空管の明るさは入力レベルと Drive に反応します。](images/04-vintage-tube.png)

### Drive、Safe、補正

| コントロール | 実用上の意味 |
| --- | --- |
| Drive | 0-100 のスケールで入力ゲイン量を設定します。通常は上げるほど密度と歪みが増しますが、結果は素材と Shape に依存します。 |
| Safe | 入力ピークに応じて実効 Drive を抑えます。実際に適用される Drive がノブで指定した値より低くなることがあります。 |
| Extreme | 同じ Drive 設定で得られるゲインを大幅に増やします。有効にするときは低い値から始めてください。 |
| Gain Comp / Comp | 実際に使用した Drive に基づく推定減衰を適用します。比較をしやすくしながら、Output は独立して調整できます。 |
| Output | 対応するチェーンの後段にある手動のレベルトリムです。別の歪みコントロールではありません。 |

Safe は Drive を管理する機能であり、最終段のマスターリミッターではありません。Gain Comp は推定値であり、ラウドネスの測定ではありません。実行中の表示は適用された補正に追従します。現在の音声テレメトリーを取得できないときは、近似記号が推定であることを示します。チェーン全体の実測レベルを比較したい場合は、トップバーのラウドネス Match を使用してください。

古いサウンドでは **Legacy Link** が表示される場合があります。このモードは、元の Drive と最終 Band Output の関係を維持します。**Use Drive Comp** はバンドを新しい補正方式へ明示的に切り替え、保存されている手動 Output 設定を再び有効にします。これによって音が変わる場合があります。パラレルチェーンでは、Legacy Link は最終 Band Output、つまり両ブランチに影響します。一方、新しい補正は Drive 自体に適用されます。

### Shape のコントロール

Shape セレクターからモデルを選びます。**Bias** はシェイピングカーブに対する信号の位置をずらして非対称性を作り、範囲は -1 から +1 です。**Rectification** は波形の負の部分を変えます。0 は極性を保持し、0.5 は負の半波を除去し、1 は負の半波を正に反転します。中間値はこれらの動作をブレンドします。Bias と Rectification は DC オフセットを生むことがあるため、必要に応じて **DC** または **DC Filter** を有効にしてください。**Mix** はシェイピングの結果と入力を混ぜます。標準の隣接した Band Drive > Shape 経路では、Drive を含む結合されたディストーション段全体に作用します。

> **Serial モードの標準 Band Shape:** オフにしても互換性のために選択したディストーションカーブは保持されます。その一方、Bias、Rectification、DC フィルターは無効になり、保存された Shape Mix は無視されます。標準 Shape の行を削除しても、この Serial の動作は残ります。したがって、Shape のコントロールがグレー表示でも、信号がクリーンであるとは限りません。ドライと比較するには Band Mix をゼロにするか、バンド全体をバイパスしてください。独立して追加した Shape は通常のウェット/ドライのバイパス動作を行います。また、Parallel A/B モードでは標準 Shape をオフまたは削除すると、そのカーブもバイパスします。

標準 Band のアナログページは、そのバンドの Drive コントロールを使用します。独立して追加したアナログ Shape には独自の Drive があり、1 つのチェーンで異なる Drive レベルの色付けを複数段重ねられます。この独立したアナログ Shape では、ローカルの Drive がモデルを直接制御します。別の Drive モジュールのスイッチを、その Shape インスタンスのコントロールと混同しないでください。

**HQ** は高いサンプルレートのディストーション経路を使い、不要なエイリアシングを減らします。明るく強く歪ませた素材や、フォールドバック設定で特に違いが出ることがあります。CPU 負荷が増すため、実際に使う予定の品質設定で試聴してください。伝達特性グラフは静的なウェーブシェイピングカーブを理解するのに役立ちますが、磁気モデルや電源変動に反応するアナログモデルの時間依存動作すべてを表すものではありません。

### デジタル Shape モデル

![デジタル Shape ページには伝達特性と非対称性のコントロールが表示されます。グラフが示すのはカーブであり、アナログモデルの動的な挙動全体ではありません。](images/06-shape-panel.png)

| モデル | 特徴と使い始めの目安 |
| --- | --- |
| Arctan | 徐々に飽和する丸みのあるカーブ。控えめな色付けに向きます。 |
| Exp | 指数関数によるソフトな飽和。クリッピングへ移行する形が異なります。 |
| Tanh | 滑らかで対称的な飽和。幅広い素材に厚みを加えます。 |
| Cubic | 丸みのある多項式クリッピング。デジタルの初期選択です。 |
| Hard | カーブの限界で急にクリップし、強い高次倍音を作ります。 |
| Sausage | クリッピング付近の角を丸めた、しっかりしたカーブです。 |
| Sin | サイン波のフォールドバックを繰り返します。Drive を上げると、単なる歪みの増加ではなく複雑な変化を生みます。 |
| Linear | 角張った変化を持つ三角波状のフォールドバックです。 |
| Limit | 狭いレベル範囲でクリップします。選択後は耳で音量を補正してください。 |
| Single Sin | 1 つのサイン波状領域を使用し、その外側のサンプルを抑えます。高い Drive では独特な質感になります。 |
| Logic | 旧来の選択項目です。現在の安定した伝達カーブは Tanh と同等です。 |
| Pit | 高レベルで減算成分を持つ飽和カーブ。高い Drive で一般的な歪みとは異なる変化を作れます。 |

名称は Fire で利用できるカーブを表しています。特定の市販ディストーションプロセッサーと同じ音を保証するものではありません。条件を揃えて比較するには、Bias と Rectification をゼロにし、1 つずつカーブを選び、出力レベルを合わせてから判断してください。

### Analog Hardware の色付け

<!-- figure:max-height=155 -->
![Tape Saturation では、音声の処理中にテープ走行の表示が動きます。この動きは選択中のモデルに伴う視覚的な表示です。](images/05-tape-detail.png)

これらは回路の挙動を参考にした色付けであり、特定のハードウェアを校正して再現したものではありません。アンプモデルには電源と動作点の挙動を、Transformer と Tape Saturation には磁気的な履歴を取り入れています。音声のレベルと履歴によって反応が変わるため、持続音と鋭いトランジェントが同じように振る舞うとは限りません。

| モデル | 使用の目安 |
| --- | --- |
| Warm Triode | ボーカル、ベース、鍵盤に、穏やかで非対称な真空管風の温かみを加えます。 |
| Bright Pentode | 素材の存在感を出したいときに、より前に出る真空管の色付けを加えます。 |
| Class A Console | 単独トラックやバスに、控えめなコンソール風の密度を加えます。 |
| Tweed Breakup | 柔らかくしなやかなギター風の歪みと、ダイナミックなクランチです。 |
| British Crunch | ギターやリズミックな素材に、中域を強調した力強いクランチを加えます。 |
| Modern High Gain | 多段で密度の高い歪み。攻撃的な音色に向きます。 |
| Diode Overdrive | リード、ベースの明瞭さ、ドラムのアクセントに向く、焦点の定まったオーバードライブです。 |
| Germanium Fuzz | 柔らかく暗めの性格を持つ非対称なファズです。 |
| Silicon Fuzz | 高次倍音の目立つ、明るく引き締まったファズです。 |
| MOSFET Drive | 穏やかな飽和と強いオーバードライブの間を埋める、非対称な色付けです。 |
| Transformer | 磁気的な色付けと、履歴に依存する飽和です。 |
| Tape Saturation | バイアスを持つ磁気録音の色付け。録音/再生とヘッド損失の特性を含みます。 |

これらの説明は試聴の目安であり、特定の音色を保証するものではありません。Tape Saturation は汎用のテープモデルで、テープ速度、バイアス、ヘッド種類のセレクターはありません。Lo-Fi にある Tape/Wow/Flutter は別の目的のコントロールです。

真空管の明るさは入力音声と Drive の両方に追従します。Drive が高いだけでは、無音時に真空管が光ることはありません。テープリールは音声の活動に反応し、処理が止まると落ち着きます。これらの描画は動作を知らせるもので、校正された電気計測器ではありません。Paper と Ink では模式的な表示になりますが、音は変わりません。

## 07. Compressor と OTT

### Compressor

Compressor は、**Threshold** を超えた信号を **Ratio** に従って小さくします。**Attack** はゲインリダクションが反応する速さ、**Release** は回復する速さを設定します。遅い Attack は最初のインパクトを残しやすく、速い Attack はそれを捉えやすくなります。Ratio を 2:1 から 4:1 程度にし、圧縮が聴こえるまで Threshold を下げ、リズムを聴きながらタイミングを調整してください。

| コントロール | 標準 Band Compressor | 追加 Compressor インスタンス |
| --- | --- | --- |
| Threshold | -48 から 0 dB | -60 から 0 dB |
| Ratio | 1:1 から 20:1 | 1:1 から 20:1 |
| Attack | 0.1-200 ms | 0.1-200 ms |
| Release | 10-2000 ms | 1-1000 ms |
| Mix | ドライから完全な処理音まで | ドライから完全な処理音まで |

標準の Band モジュールは旧来の範囲を維持しています。Band または Master に追加したインスタンスには、上表の追加モジュール用の範囲が適用されます。Ratio が 1:1 のときは圧縮しません。Compressor に専用のメイクアップゲインノブはありません。適切な Output コントロールやチェーン構成でレベルを戻してください。Mix を下げるとモジュール内でパラレルコンプレッションができ、チェーンのパラレルブランチを使えば、ドライと圧縮音をそれぞれ別に処理できます。

### OTT: 小さな細部を持ち上げ、大きなピークを抑える

標準 Band モジュールでは、しきい値を **Up Thresh** と **Down Thresh**、出力トリムを **Gain** と表示します。独立して追加した OTT では、同じ役割のコントロールを **Up**、**Down**、**Output** と表示します。

OTT は上方向と下方向の圧縮を組み合わせます。**Up / Up Thresh** より小さい音を持ち上げ、**Down / Down Thresh** より大きい音を抑え、その間の領域には比較的少なく作用します。周波数の分離は Fire のマルチバンド分割が担います。1 つの Master OTT は入力全体に作用し、内部で別のクロスオーバーバンドを作るわけではありません。

![Master OTT は Band OTT と同じ LIFT / PRESS 表示を使います。入力、ゲイン変化、ダイナミクスの動きは、選択中の OTT インスタンスから取得します。](images/09-ott-panel.png)

| コントロール | 範囲と動作 |
| --- | --- |
| Depth | ダイナミクス処理全体の強さをゼロから最大まで設定します。標準 Band では 0-1、追加インスタンスではパーセント表示です。 |
| Time | 10-400%。Attack と Release を同時に拡大縮小します。100% は Attack 5 ms、Release 100 ms に相当します。 |
| Up / Up Thresh | -72 から -6 dB。小さな信号のしきい値です。Downward より少なくとも 6 dB 低く保たれます。 |
| Down / Down Thresh | -36 から 0 dB。大きな信号のしきい値です。 |
| Output / Gain | -24 から +24 dB。ダイナミクス処理後のレベルトリムです。 |
| Mix | ドライから完全な処理音まで。 |

上方向と下方向の比率は 4:1 と 8:1 に固定され、ソフトニーを使用します。上方向のゲインには上限があり、ノイズフロア付近では効果が減衰します。OTT がノイズを生成するわけではありません。両チャンネルは検出器とゲインを共有し、ステレオの関係を維持します。

**LIFT / PRESS** 表示は、選択中のモジュールの動きを示します。持ち上がるリボンは上方向の圧縮、押し下げる動きは下方向の圧縮を表します。Master Lab を含め、独立して追加した各 OTT に専用の値があります。ダイナミクスの動きには Output トリムを含まないため、Output だけを上げても圧縮が強くなった表示にはなりません。

標準 Band OTT では、スペクトラムのしきい値の線を直接操作することもできます。上下にドラッグして変更し、ダブルクリックでリセットします。フォーカスがあるときは矢印キーで精密に変更できます。控えめな Depth から始め、部屋の響きやノイズが目立ちすぎる場合は下げてください。Time が 100% 未満では素早い反応が強調され、長い設定では動きがゆっくりになります。

## 08. Stereo

Stereo には **Width**、**Pan**、**Mix** があります。Width はステレオ信号の中央成分と差成分のバランスを変えます。ニュートラルな位置は標準 Band モジュールでは **0.50**、追加インスタンスでは **50%** です。低い設定では中央、高い設定ではサイドを重視します。両端では反対側の成分が除去されるため、100% は単に「通常のステレオを最大幅にする」という意味ではありません。

Pan は左右へ動かすと反対側のチャンネルを減衰させます。Mix はステレオ処理とモジュール入力をブレンドします。幅を広げるにはステレオ情報が必要です。差成分のない中央の信号から、Width だけで独立したサイドの細部を作ることはできません。モノラルの処理バスでは、このステレオ処理をバイパスします。

幅の広い設定では、スペクトラムを **Mono** にし、耳でもモノラル比較を行ってください。差成分を強調する方法で広げると、モノラル合成時の音がかなり小さくなる場合があります。Width を下げる、モジュールの Mix でドライを増やす、または低域バンドの幅をニュートラルに近づけると調整できます。

## 09. EQ と Dynamic EQ

各 EQ は最大 **12 ポイント**に対応します。番号付きポイントを選び、**Frequency**、**Gain**、**Q**、**Filter Type**、対応する場合は **Slope** を編集します。**+** でポイントを追加し、**-** で削除します。各ポイントには個別の電源コントロールがあります。モジュールがバイパスされていても EQ を編集できます。ポイントを追加すると、試聴できるようモジュールが有効になります。

![Master EQ。スペクトラム上のポイントと選択中のポイントのコントロールを表示しています。ポイントの切り替えとタイプメニューを使い、目的のフィルターを編集します。](images/07-master-eq.png)

### スタティック EQ

| タイプ | 用途 |
| --- | --- |
| Bell | 選んだ周波数付近をブーストまたはカットします。 |
| Low cut | カットオフより低い周波数成分を除去します。 |
| High cut | カットオフより高い周波数成分を除去します。 |
| Low shelf | 広い低域を調整します。 |
| High shelf | 広い高域を調整します。 |
| Notch | 狭い周波数領域を除去します。Gain は使用できません。 |
| Band pass | 中心周波数付近の領域を残します。Gain は使用できません。 |

カットフィルターのスロープは **12、24、36、48 dB/oct** から選べます。Q は帯域幅またはレゾナンスを調整します。Gain は -24 から +24 dB、Frequency は 20 Hz-20 kHz です。利用可能な応答はホストのサンプルレートにも依存します。追加 EQ のポイントは Q 0.1-20 に対応します。標準 Master EQ の最初の 3 ポイントは Q 1-5 を維持し、それ以降のポイントは Q 0.1-18 に対応します。

標準 Master EQ は、スペクトラム上での編集にも対応します。空白部分をダブルクリックすると、その位置に Bell を追加します。ポイントをドラッグして周波数/ゲインを変え、ポイント上でスクロールして Q を調整します。そのスペクトラムにフォーカスがあるときは、Delete/Backspace で選択中のポイントを削除できます。これらは Master EQ 編集表示の操作です。バンドのスペクトラムにクロスオーバーを追加する操作と混同しないでください。

### Dynamic EQ

<!-- figure:max-height=165 -->
![Dynamic コントロールは、選択した Bell または Shelf ポイントに属します。Range はゲイン変化の方向と最大量を決めます。](images/08-dynamic-eq.png)

**Bell**、**Low shelf**、**High shelf** のいずれかを選び、ポイントのヘッダーにある **Dynamic** を開いて有効にします。他のフィルタータイプではダイナミクスを利用できません。

| コントロール | 意味 |
| --- | --- |
| Threshold、-60 から 0 dB | 検出器がゲイン変更を要求し始めるレベルです。 |
| Ratio、1:1-20:1 | レベルに応じた反応の強さです。1:1 では変化しません。 |
| Range、-24 から +24 dB | 符号付きの最大ゲイン変化量です。負は減衰、正はブーストです。 |
| Attack、0.1-200 ms | レベル上昇に反応する速さです。 |
| Release、5-2000 ms | 回復する速さです。 |

検出器は、EQ モジュールの元の入力をそのポイントの周波数付近でフィルタリングし、左右の大きい方のピークを使います。外部サイドチェインの選択機能ではなく、同じ EQ 内の前のポイントの出力が直列に送られるわけでもありません。基準 Gain とダイナミックゲインの合計は ±24 dB 内に収まります。

音声を再生しながら、ダイナミックなゲイン変化と実効ゲインの表示を確認してください。標準 Master EQ のライブカーブは実効ゲインに追従しますが、ドラッグ可能なポイントと Gain ノブは基準設定を維持します。ダイナミクス設定はホストオートメーション、プリセット、パラメーターロック、チェーンのコピーに対応しますが、Fire 内部のモジュレーションの宛先にはできません。Frequency、Gain、Q は通常どおりモジュレーションに対応します。

## 10. Chorus、Flanger、Phaser

これらのエフェクトは独自の内部スイープで周期的な動きを加えます。Rate ノブの単位は Hz です。内部オシレーターと、別に用意されている LFO バンクを混同しないでください。公開されているエフェクトコントロールは、Fire のモジュレーションシステムでも動かせます。

| エフェクト | コントロールと範囲 |
| --- | --- |
| Chorus | Rate 0.05-8 Hz、Depth 0-100%、Delay 5-30 ms、Feedback -75 から +75%、Width 0-100%、Mix 0-100%。 |
| Flanger | Rate 0.05-8 Hz、Depth 0-100%、Delay 0.1-10 ms、Feedback -90 から +90%、Width 0-100%、Mix 0-100%。 |
| Phaser | Rate 0.05-8 Hz、Depth 0-100%、Center 40-6000 Hz、Feedback -85 から +85%、Width 0-100%、Mix 0-100%。 |

Chorus は動く短いディレイを使い、厚みとピッチの揺れを加えます。Flanger はより短いディレイを掃引し、ドライ音と混ざることで金属的なくし形のパターンを作ります。Phaser は 6 段のオールパスチェーンを使い、移動するノッチによる丸みのあるスイープを作ります。

Depth はスイープ量を設定します。Delay は Chorus/Flanger の中心ディレイ時間、Center は Phaser のスイープする周波数領域です。Feedback はレゾナンスを強め、負の値では異なる性格になります。Width は左右のスイープをずらし、ゼロでは両者が揃います。Mix はドライ信号と処理信号の干渉の仕方を決めます。

Flanger/Phaser の打ち消しをはっきり聴くには、Mix 50% 付近から始めてください。遅い Rate と控えめな Depth はパッドに合い、速い Rate は打楽器や鍵盤に活発な動きを加えます。100% ウェットでは、ドライ信号が打ち消しに参加しなくなるため、性格が大きく変わることがあります。

## 11. Delay

Delay には **Time**、**Feedback**、**Tone**、**Ping-Pong**、**Sync**、**Mix** があります。Sync が **Free** の場合、Time は **10-2000 ms** です。同期の選択肢は **1/16、1/8、1/8 D、1/4、1/4 D、1/2、1 Bar** で、D は付点を表します。同期時間はホストのテンポに従いますが、ディレイ容量は 2 秒までです。遅いテンポで長い音価を選ぶと、指定した長さに達する前にこの上限に制限される場合があります。

Feedback は 0-90% で反復回数を制御します。Tone は 500 Hz-18 kHz でフィードバック経路をフィルタリングし、低い値ほど後続の反復音が暗くなります。Ping-Pong は 0-100% で、通常のステレオディレイから左右交互の反復へ変化します。Mix はドライ入力に対するエコーのレベルを設定します。

ボーカルのスラップには、Free モードで 80-130 ms 付近、低い Feedback、小さめの Mix を試してください。リズミックな動きには付点 8 分音符と控えめな Feedback を選び、原音と競合する場合は Tone を下げます。専用リターントラックでは Mix 100% が出発点として便利ですが、インサートではもっと低い値から始めてください。

## 12. Reverb

**Classic、Room、Hall、Plate、Spring、Chamber** から選びます。どのモデルも同じ 6 つのコントロールを使うため、モデルごとに別のパネルを覚えずに比較できます。

![追加 Reverb には、アルゴリズムメニューと Size、Damping、Pre-delay、Width、Low Cut、Mix があります。](images/10-reverb-panel.png)

| コントロール | 意味 |
| --- | --- |
| Size、0-100% | 空間/減衰の性格を変えます。校正された残響時間の表示ではありません。 |
| Damping、0-100% | 高い値ほど循環する残響尾部が暗くなります。 |
| Pre-delay、0-200 ms | 残響音が始まるまでの遅延です。原音と残響を分離しやすくします。 |
| Width、0-100% | 残響のステレオの広がりです。 |
| Low Cut、20-1500 Hz | リバーブへ入る低域エネルギーを除去します。 |
| Mix、0-100% | ドライ音と残響音のバランスです。 |

**Classic** は Fire の元のリバーブの性格を維持します。**Room** は小さな空間感と、聴き取れる初期反射を作る出発点に向きます。**Hall** は広く変化する空間に向きます。**Plate** はボーカル、スネア、持続音に密度の高い残響を加えます。**Spring** は分散を伴うスプリング風の色付けで、ギターやサウンドデザインに役立ちます。**Chamber** は親密な質感から広い質感までをつなぐ、別の初期反射と減衰パターンを提供します。いずれもアルゴリズムによる空間であり、特定の部屋やハードウェアの畳み込み収録ではありません。

モデルを変更すると、ドライ音を経由してフェードしながら前のモデルのディレイ履歴を消去します。そのため、以前の残響がそのまま続くとは考えないでください。ボーカルを明瞭にするには、単に Mix を下げる前に Pre-delay と Low Cut を増やしてみましょう。ドラムのパンチを残すには、短く感じる Size を選び、リバーブを控えめに使うかパラレルブランチに配置します。

## 13. Lo-Fi

Lo-Fi はサンプルレート低減、量子化、テープ風の揺れを組み合わせます。**Rate** は低減率です。値を大きくするとサンプルを長く保持し、より粗く低レートらしい性格になります。**Bits** は振幅の解像度を下げます。**Jitter** は別のノイズを足すのではなく、サンプル保持のタイミングを揺らします。

**Tape** は飽和と高域の柔らかさを加えます。**Wow** は遅いピッチの漂い、**Flutter** は速い変動です。**Mix** は Lo-Fi 全体の処理結果を混ぜます。Rate と Bits の低減をはっきり聴くには、Tape/Wow/Flutter をゼロから始め、色付けを 1 つずつ加えてください。

標準 Master Lo-Fi は Rate **1-64** と Bits **4-32** を維持します。追加 Lo-Fi は Rate **1-32**、Bits **4-24** を使い、Tape、Wow、Flutter、Jitter はそれぞれゼロから最大量まで設定できます。追加コントロールがパーセント表示なのに対し、標準コントロールでは正規化された 0-1 の値を表示することがありますが、音作り上の役割は同じです。

使い込まれた鍵盤の質感には、軽いレート低減、比較的高い Bits、少量の Tape、ゆっくりした Wow を試してください。ざらついたドラムには、先に Bits を下げ、アタックに好みの粒立ちが出るまで Rate と Jitter を増やします。Lo-Fi の Tape は簡潔な色付けコントロールであり、専用の **Shape > Tape Saturation** がより詳細な磁気モデルです。

## 14. Chord Resonator

Chord Resonator は、入力音声で調律された倍音バンクを励起します。打楽器、ノイズ、倍音の豊かな素材に特に向いています。曲のキーを検出したり、任意の音を音階へ調律し直したりするものではありません。

**Root** を **C2 から C5** で選び、**Chord** を **Major、Minor、Major 7、Minor 7、Sus 2、Sus 4、Fifth、Octave** から選びます。音名表示でボイシングを確認できます。Fire では中央のドを C4 と呼びます。

**Color** は基音と上の倍音のバランスを調整します。**Decay** は公称 60 dB 減衰時間を **0.05-3 秒**に設定します。**Width** は各ボイスをステレオに広げます。ゼロでは各ボイスの左右の重みが等しくなりますが、入力のステレオチャンネルは保持されます。**Mix** は素材のアタックと響く和音のバランスを調整します。

打楽器ループでは、初期値の C3 Minor 7、控えめな Decay、低い Mix から始めます。曲に合う Root を選んでください。低い基音を直接残したい場合は、中高域のバンドに配置します。励起に使うのは音声なので、MIDI 入力は不要です。新しい音声がなくなると、既存の残響だけが続きます。

## 15. Granular、Freeze、サンプルファイル

Granular は、Mutable Instruments Clouds の**通常のグラニュラーモード**を Fire 向けに適応したものです。入力音声を短い循環バッファーに録音し、そこから重なり合う断片を再生します。エンジンは **32 kHz ステレオ、16-bit** の音声を使い、ホストのレートとの間で変換を行います。これも質感の一部です。透明なドライ信号は別に保持されます。

![展開した Granular ページ。Clouds のコントロール、Freeze、Sample の入口を備えています。](images/11-granular-panel.png)

### グレインのコントロール

| コントロール | 動作 |
| --- | --- |
| Position | 録音内の位置を選びます。時計回りに動かすと古い音声に近づきます。 |
| Size | グレインの長さを 0-100% で設定します。 |
| Pitch | グレインを -24 から +24 半音の範囲で移調します。 |
| Density | 負の側では規則的に、正の側ではランダムにグレインを生成します。中央では新しいグレインを生成しません。 |
| Texture | グレインのエンベロープを鋭いものから滑らかなものへ変え、高い設定では拡散を加えます。 |
| Spread | グレインのステレオ配置を調整します。 |
| Feedback | グラニュラー出力を処理経路に戻します。 |
| Reverb | Clouds エンジン独自の空間音を加えます。 |
| Mix | 入力ドライ音とグラニュラー出力のバランスです。 |
| Freeze | 録音の更新を止め、グレインの再生は続けます。 |

Freeze がオンなのに音が出ない場合は、録音が存在するか、Density が中央から離れているか、Mix がゼロより大きいかを確認してください。Freeze が保持するのは素材です。すべてのグレインやリバーブの残響を、完全に同じ状態で保持するわけではありません。録音が空の場合は、新しい音声を取り込んでから保持します。

### ライブの質感を取り込む

1. Freeze をオフにして、短い素材を Granular モジュールに通して再生します。
2. Density を中央から離し、グレインが聴こえる程度に Mix を上げます。
3. 残したい瞬間に **Freeze** を押します。
4. 保持した素材が再生されている間に Position、Size、Pitch を動かします。
5. 控えめな Feedback または Reverb を加え、より持続する質感にします。
6. プリセットまたはホストのプロジェクトを保存し、フリーズした録音をサウンドと一緒に保持します。

完成したフリーズ録音は、プリセット、プロジェクト状態、A/B スナップショット、持ち運び可能なモジュール/チェーンファイルに埋め込まれます。再読み込みではステレオ内容とリング位置を含む録音が復元されますが、スケジュール済みグレインやディレイ/リバーブ履歴は再開始します。フリーズした質感を再生するには、ホストが音声処理を継続している必要があります。

### ファイルをインポートする

Freeze 横の **Sample** をクリックして **Granular / Sample** を開き、**Choose audio** を押します。ファイル選択画面から対応するモノラルまたはステレオファイルを選んでください。利用可能なデコード形式はビルド/プラットフォームに依存します。元ファイルのサンプルレートは **8-384 kHz** に対応し、モノラル素材は両チャンネルにコピーされます。

![ファイルを選ぶと Sample に選択範囲が表示され、Import and Freeze が有効になります。Normalize は任意で、初期状態ではオフです。](images/12-granular-import.png)

録音の最大長は **1.02175 秒**、つまり **32 kHz で 32,696 ステレオフレーム**です。ホストのサンプルレートを上げても、この容量は増えません。長い素材では開始コントロールを動かすか開始時間を入力し、選ばれた部分の波形を確認します。この波形はインポートする範囲の視覚的なプレビューであり、別の試聴再生ボタンではありません。

**Normalize to -1 dBFS** は初期状態ではオフです。有効にすると、変換後に左右のバランスを変えず、ステレオ共通のピークを設定します。振幅を維持したい場合はオフのままにしてください。元のピークが保存先の範囲を超えるとクリップする場合があります。範囲が決まったら **Import and Freeze** をクリックします。Fire はこのモジュールの録音だけを置き換え、Freeze を有効にします。再生中には短いウェット音の遷移が入ります。

インポートは 1 回の Undo 操作として扱われます。Undo で以前のフリーズ録音と設定を復元できます。以前にライブ録音していた場合は、Undo でライブモードに戻りますが、過去の循環音声を再構築することはできません。インポートした録音は埋め込まれるため、元ファイルをディスクに残す必要はありません。エディターを閉じたり対象モジュールを置き換えたりすると、処理待ちのインポートは別の対象へ向け直されずキャンセルされます。

### フリーズ素材をエクスポートする

<!-- figure:max-height=215 -->
![ライブで取り込んだ録音は Sample からエクスポートできます。Start、Normalize、Import and Freeze は、インポート用ファイルを選ぶまで使用できません。](images/12-granular-sample.png)

有効なフリーズ録音がある状態で Sample を開き、**Export frozen WAV** をクリックします。保存先を選び、同名のファイルがある場合は置き換えを確認します。Fire は保存先の選択画面を開く前に録音を確保するため、その後のパラメーター変更は書き出し用スナップショットに影響しません。

WAV には、時系列に並んだ **ステレオ 16-bit / 32 kHz** の音声が入ります。書き出すのは保存された録音自体であり、グレインの生成タイミング、Pitch、Feedback、Reverb、Mix は**適用されず**、エクスポート時に追加のノーマライズも行いません。インポート時にノーマライズした場合、その結果はすでに録音へ反映されています。処理後のグラニュラー演奏を残したい場合は、ホストで Fire の出力を録音またはレンダリングしてください。短い録音は存在するフレームだけを書き出し、最大容量まで人工的に引き伸ばすことはありません。

Clouds の別モードである stretch、looping-delay、spectral は含まれていません。ハードウェアのトリガー入力や別の低音質モードもありません。搭載されている通常のグラニュラーモードでも、Freeze とモジュレーションを組み合わせて多彩な変化を作れます。

## 16. モジュレーションルーティングとマクロ

Fire は最大 16 の LFO、4 つのエンベロープ、4 つのマクロ、4 つの MIDI CC ソースを提供します。モジュレーションマトリクスで、これらのソースを対応する宛先コントロールに接続します。1 つの宛先に複数のルーティングを割り当てられ、各寄与を加算した最終結果はそのパラメーターの範囲内に制限されます。

### 最初の LFO 割り当て

1. **Mod Forge** を開き、左の一覧から LFO を選びます。バンクが空なら **+** を使います。
2. Rate を設定します。ホストテンポの音価に合わせるには **BPM** を有効にし、自由な速度にするにはオフにします。
3. **Assign** をクリックしてから、Band Lab または Master Lab の宛先コントロールをクリックします。対応するノブを右クリックし、**Add modulation source** の項目から選ぶこともできます。
4. グリッド/Matrix コントロールを開いてルーティングを確認します。Depth を調整し、**Bi** または **Uni** を選びます。
5. ノブの周りにあるソース色の範囲を確認します。ニュートラル位置の目盛りが基準値を示し、輪郭のある動く点がモジュレーション後の値を示します。

マトリクスの **Add routing** で接続を追加します。各行には Source、Destination、Depth、極性、有効/バイパス、削除のコントロールがあります。ルーティングをバイパスすると割り当ては残りますが、寄与は止まります。割り当て済みノブを右クリックすると、**Edit modulation in matrix** または **Clear all modulation** を選べます。複数のルーティング、またはカスタム範囲のソースバッジをクリックすると、対応するルーティングが開きます。

Destination をクリックすると検索可能な選択画面が開きます。コントロール、モジュール、パラメーター ID、バンドで検索し、対象範囲/モジュールで絞り込めます。**Active chain** は現在のモジュールを中心に表示し、**All targets** は存在しないモジュールや非アクティブなバンドも含めます。利用できない割り当ても保存しておけますが、表示しただけではモジュールは挿入も有効化もされません。**Show control** は対象ページを開き、ノブにフォーカスを移します。選択画面では、Down で検索欄から結果へ移動し、Enter で選択、Escape でキャンセルします。

<!-- pagebreak -->

### ルーティングのマッピング一覧

| 項目 | 意味 |
| --- | --- |
| **Depth** | -100% から +100%。マッピングのオフセットを拡大縮小します。 |
| **Bi** | 標準のバイポーラーオフセット。対象の正規化範囲の -50% から +50% です。 |
| **Uni** | 標準のユニポーラーオフセット。0% から +100% です。 |
| **From / To** | 基準ノブからのカスタムオフセットで、それぞれ -100% から +100% です。どちらかを編集するとカスタム範囲が有効になります。 |
| **Curve** | Linear、Ease in、Ease out、S curve。両端の間を補間する前に適用します。 |
| **Depth via** | Fixed、またはルーティングの Depth をゼロから最大まで拡大縮小するマクロです。 |

オフセットはパラメーターの**正規化範囲**に対する割合であり、Hz や dB の数値に対して線形とは限りません。例えば Depth 100%、From -20%、To +30% は、基準ノブに対してその範囲を動かします。Depth 50% では両方のオフセットが半分になります。Bi/Uni をクリックすると、それぞれの標準の端点に戻ります。Depth via のマクロはルーティングを拡大縮小するもので、ソースを置き換えるものではありません。そのルーティングを聴くには、マクロをゼロより上にしてください。

ソースのコントロールで自分自身を再帰的に変調することはできません。ルーティングモードと構造的なモジュール割り当ては、通常の内部モジュレーション対象ではありません。パラレルのバランスを動かすには、ルーティングモードではなく Blend を対象にします。

## 17. LFO 波形と再生

![実際に編集できる三角波を表示した Mod Forge。一覧から LFO を選び、カーブを編集してから宛先を割り当てます。](images/14-mod-forge-panel.png)

Fire は 4 つの LFO から始まり、最大 16 まで増やせます。スクロール可能な LFO BANK で 1 つを選びます。ソースを削除するとそのルーティングも消えますが、他のソースの番号は変わりません。スロットを再使用すると、新しい波形/タイミング設定から始まります。すべての LFO を削除しても、エンベロープ、マクロ、MIDI CC は利用できます。

エディターには **Edit** と **Brush** モードがあります。Edit では、空白をダブルクリックしてポイントを追加し、ポイントをドラッグして移動し、ポイントをダブルクリックして削除します。最初と最後のポイントは削除できません。区間をドラッグするとカーブを曲げられます。Shift を押しながらドラッグすると範囲選択でき、選択済みポイントをドラッグすると選択全体が移動します。グリッドにスナップするには、macOS では Cmd、Windows では Ctrl を押しながらドラッグします。X/Y のグリッドコントロールで分割数を設定します。

エディターを右クリックすると、**Select All**、**Clear**、**Copy**、**Paste**、**Invert Horizontally**、**Invert Vertically** が使えます。Clear は直線の初期波形に戻します。Brush モードでは、左マウスボタンで選択中のプリセット区間を描きます。Saw Up、Saw Down、Sine Convex、Sine Concave、Square High、Square Low などを選べます。

Rate は速度、BPM は同期、Smooth は描いた波形の滑らかさ、Phase は読み取り位置のオフセットを設定します。動くハイライトは音声で実際に使われる位相に追従します。ホストのトランスポートが停止していても、音声コールバックが続いていれば動くことがあります。コールバックが止まると保持/フェードします。

### 再生モードと再現可能なランダム動作

選択中の LFO の **Playback** をクリックします。

| 設定 | 動作 |
| --- | --- |
| **Loop** | フリーランまたはテンポ同期で継続的に再生します。 |
| **Retrigger** | 条件に合う MIDI Note On または手動 Trigger で周期を再開始し、その後ループします。 |
| **One-shot** | トリガーごとに 1 周期を再生し、最後の値を保持します。 |
| **Shape** | 描いた波形を読みます。Smooth はこのモードに作用します。 |
| **Random Hold** | ランダムな値の間を段階的に移動します。 |
| **Random Glide** | ランダムな値の間を補間します。 |

Trigger Note は 0-127 または **Any**、チャンネルは 1-16 または **Omni** を選びます。Note Off ではトリガーしません。**Trigger** は MIDI 入力なしで Retrigger または One-shot を手動開始します。Seed は 0-65535 です。同じシードとトリガー列でランダム列を再現できます。トリガーごとにランダム列が先へ進み、常に同じ最初の値へ戻るわけではありません。

描画と Smooth が作用するのは Shape だけです。Random の One-shot は Phase を無視します。Hold は 1 つのランダム値を保持し、Glide は 1 回の遷移を完了します。Shape の One-shot は Phase の位置から始まり、それでも完全な 1 周期を再生します。Playback 設定とシードはサウンドに保存されますが、手動の Trigger 操作自体は保存されません。

![Playback では Loop/Retrigger/One-shot、Shape またはランダム波形、MIDI トリガーの条件、乱数シードを設定します。](images/17-lfo-playback.png)

## 18. エンベロープと外部サイドチェイン

**Matrix > Envelopes / Macros** を開き、**ENV 1-4** を選びます。各エンベロープフォロワーの検出器には、独立した入力、フィルター、Attack、Release、Sensitivity があります。

![各 ENV は独立した検出入力とフィルターを持ちます。この例では External sidechain を選んでいます。実際の信号はホスト側から送る必要があります。](images/16-envelopes-macros.png)

| コントロール | 範囲/用途 |
| --- | --- |
| **Detector** | Main input、External sidechain、または Band 1-4。 |
| **High Pass** | 20 Hz-20 kHz。専用の有効スイッチを持ち、初期値は 80 Hz、バイパス状態です。 |
| **Low Pass** | 20 Hz-20 kHz。専用の有効スイッチを持ち、初期値は 12 kHz、バイパス状態です。 |
| **Attack** | 0.1-500 ms。初期値は 10 ms です。 |
| **Release** | 5-2,000 ms。初期値は 200 ms です。 |
| **Sensitivity** | -24 から +24 dB。初期値は 0 dB です。 |
| **Hold to listen** | 選んだフィルター済み検出信号を一時的に試聴します。 |

Main と Band のソースはエフェクト前から取得します。Band の検出器は、ソロと出力ゲインの前で、独自の 24 dB/oct フィルターによって現在のクロスオーバー境界に追従します。非アクティブなバンドや未接続のサイドチェインは無音です。ステレオのエネルギー検出は逆極性の入力にも反応します。検出フィルターが変えるのはエンベロープの聴く信号であり、処理音の EQ ではありません。

色付けを演奏に反応させるには、Main input を選び、速い Attack と適度な Release を設定し、その ENV を Shape Mix または Drive に控えめな正の Depth で割り当てます。弱い演奏でも有効な動きが出るまで Sensitivity を上げます。音符の間で滑らかに戻るよう Release を調整し、効果が過剰にならないよう Depth を詰めてください。

外部制御では、ホストで別のトラックを Fire のサイドチェイン入力へ送り、**External sidechain** を選び、マトリクスでその ENV を割り当てます。適切なレベルまたは Mix コントロールに負の Depth で割り当てると、サイドチェインが大きくなるほどダッキングできます。正確な接続方法は DAW とプラグイン形式によって異なります。External sidechain を選んだだけでは、ホスト側の接続は作成されません。

フィルター済みの検出信号を確認するには、マウスで **Listen** を押し続けるか、フォーカスがある状態で Space/Return を押し続けます。離すと通常の出力に戻ります。パネルを隠す/閉じる操作でも試聴は終了します。これは一時的な試聴状態であり、保存もオートメーションもされません。

最初の検出器は、コントロールのタブでは **ENV 1** ですが、ソースメニューでは **Envelope** と表示される場合があります。残りの検出器は ENV 1 のコピーではなく、それぞれ別のソースです。

## 19. MIDI コントロール

**Mod Forge > MIDI** を開きます。4 つのスロットそれぞれで、指定チャンネルまたは Omni の CC 0-127 を受信できます。**Off** はそのスロットを無効にします。

1. ホストで、コントローラー/トラックの MIDI を Fire へ送ります。
2. スロットの **Learn** をクリックし、使いたいハードウェアコントロールを動かします。Fire が CC 番号とチャンネルを取得します。Learn をもう一度クリックするかパネルを閉じるとキャンセルします。
3. Matrix を開き、対応する **MIDI CC 1-4** ソースを宛先に割り当てます。
4. LFO のルーティングと同様に範囲、カーブ、Depth を設定します。同じコントローラーをどのチャンネルでも使うには Omni を選びます。

![4 つの MIDI CC スロットは直接設定するか Learn で割り当てられます。ホストが Fire へ MIDI を届けると、モジュレーションソースとして利用できます。](images/18-midi-controls.png)

MIDI CC 設定は保存されますが、受信したコントローラーの位置はライブ演奏データです。ホストが Fire に MIDI を送る必要があります。Fire は AU エフェクトとしての識別を維持しているため、一部の AU ホストでは MIDI を送れません。ホストがエフェクトへの MIDI ルーティングに対応する場合は VST3 または CLAP を使うか、通常のパラメーターオートメーションを使ってください。MIDI ノートは LFO をトリガーできますが、Fire をシンセサイザーにするものではありません。

## 20. 実践的なサウンドデザイン例

以下は音作りの出発点であり、ファクトリープリセットの仕様ではありません。最初に素材を適切な試聴レベルへ下げ、処理後に音量を揃えてください。編集前に目的のバンドを選び、モジュールの電源がオンであることを確認します。

### ギター: タッチに反応するブレイクアップ

1. 1 バンドから始め、Shape の前に Drive を置きます。
2. **Tweed Breakup** を選び、控えめな Drive、Safe オン、Extreme オフで始めます。
3. 基本の性格を探す間は Bias と Rectification をゼロ付近に保ちます。弱くも強くも演奏しながら Drive を調整します。
4. 低い音が歪みを支配する場合は Shape の前に EQ を置きます。生成された音色が暗すぎる/鋭すぎる場合は後に置きます。
5. **Spring** Reverb を少量の Mix で加え、残響で低域が濁る場合は Low Cut を上げます。
6. 結果の音量を合わせます。Fire のギター風の色付けはディストーション段であり、完全なキャビネット/マイクシミュレーターではありません。

### ベース: 重みを残して輪郭を加える

1. 低い基音の領域を比較的クリーンに残せるよう分割します。クロスオーバーは耳で決めてください。
2. 高い方のバンドを選び、**Warm Triode**、**Diode Overdrive**、**Transformer** を試します。
3. 小さなスピーカーでも音符が明確になるまで Drive を上げます。荒くなりすぎる場合は、そのバンドの Mix を下げます。
4. 高い音のダイナミクスが変わりすぎる場合は、控えめな Ratio の Compressor を使います。
5. Solo を解除した全体と、モノラルの両方で確認します。低域バンドで極端な Width を使うのは避けてください。

### ボーカル: 常に耳障りになることなく密度を加える

1. 1 バンド、または穏やかなバンド別処理を使います。低い Drive で **Class A Console** または Warm Triode を加えます。
2. Shape の後に EQ を置き、耳で見つけた耳障りな周波数に Bell を作ります。
3. そのポイントの Dynamic を有効にし、負の Range を選び、強いフレーズだけで減衰が必要になるよう Threshold を下げます。
4. 言葉を残響から分離できる Pre-delay と、明瞭さを保つ Low Cut を設定した **Plate** Reverb を加えます。
5. 音量を揃えて比較し、子音が自然なままか確認します。

耳障りなボーカルの共鳴を抑えるには、問題の周波数に Bell を置き、基準 Gain を 0 dB 付近にし、Range を負にして、大きな音節で減衰するまで Threshold を下げます。最初は控えめな Range にしてください。継続的な深いカットよりも、ときどき数 dB を制御することが目的になる場合が多いためです。

### ドラム: パラレルでエネルギーを加える

1. チェーンの Routing を開き、**Parallel A/B** を選びます。
2. 直接音の経路にするため、A から既存の処理モジュールをすべて移動または削除します。その後 B に **OTT** と、必要なら Shape を置きます。
3. OTT の Depth を適度に設定し、Up / Up Thresh で小さな打音を引き出し、Down / Down Thresh でピークを抑えます。
4. Blend を A 側付近から始め、ドライのアタックを失わずにグルーヴの密度が増すまで B を加えます。
5. B に Lo-Fi を試して質感を加え、近い出力レベルでループ全体を比較します。

### パッドとトランジション: フリーズした雲

1. Granular を追加して持続する和音を送り込むか、**Sample** から適切な部分をインポートします。
2. Freeze を有効にし、Density を中央から離し、滑らかな Texture を選びます。
3. 暗い下地には Pitch を下げ、軽いレイヤーには上げます。不要なクリックや不安定な部分を避けるよう Position を調整します。
4. Position または Size に遅いモジュレーションを加え、範囲を抑えて調整します。
5. 後に Hall Reverb を置くか、同じパラレルブランチに配置して、Blend で質感を徐々に導入します。
6. フリーズ録音を含めてプリセットを保存します。元素材が必要な場合だけ未処理の WAV をエクスポートし、変化するエフェクト全体を残すにはホストでレンダリングします。

### 演奏用マクロ: 複数の宛先をまとめて動かす

宛先ごとにルーティングを追加し、それぞれ同じ Macro ソースを選びます。個別に Depth と極性を設定してください。例えば、1 つのマクロでディストーションの Drive を上げ、Output を下げ、リバーブの Mix を少し増やせます。ゼロから始め、聴きながら徐々に回します。役割が定まったらメインページで名前を変更します。4 つのマクロは、短い値のランプ処理を備えた、ホストオートメーション対応の 0-100% コントロールです。名前、値、ルーティングは、サウンド、A/B、プロジェクトに保存されます。

## 21. 設定、パフォーマンス、トラブルシューティング

**Menu > Skin > Modern / Vintage / Paper / Ink** を選ぶか、Settings の 4 つの外観ボタンを使います。音と Undo 履歴は変わりません。Modern はグラファイト/アルミニウム、Vintage は木材と物理的なコントロール、Paper と Ink は明るい/暗い配色の細線図を使います。スキンはローカルの設定です。新しいインスタンスは保存された選択を使い、すでに開いているインスタンスはそれぞれの選択を保持します。エディターの隅でサイズを変えられ、対応する寸法内で 2:1 の配置を維持します。

![Settings には外観の選択と、ローカルにコピーできる診断情報があります。この画像はマニュアル用テストホストのもので、実際の DAW や音声設定とは異なります。](images/22-settings.png)

**Menu > Settings** には、バージョン、リビジョン/ビルド情報、形式、アーキテクチャ、ホスト、サンプルレート、ブロックサイズ、チャンネル、レイテンシー、HQ 状態が表示されます。**Copy diagnostics** は情報を更新し、報告に貼り付けられるようローカルにコピーします。自動送信は行いません。Settings には **Auto-check for updates on startup** もあり、メニューには **Check for New Version** があります。

| 症状 | 確認すること |
| --- | --- |
| ホストに Fire が見つからない | ホストが対応する形式をインストールし、再起動/再スキャンを行い、検証結果や無効化されたプラグイン一覧を確認します。macOS の AU と VST3 は別のバンドルです。 |
| 古いバージョンが表示される | 置き換え後にホストを再起動します。Settings のバージョン/リビジョンと、ホストが読み込んだ形式/パスを確認してください。複数のインストールが共存する場合があります。 |
| 音が出ない | 音声がトラックに届いているか、音源が Fire の前にあるか、ホストのルーティング/出力が有効か確認します。バンドのソロ/電源、Output/Mix、極端なモジュレーション、フリーズした Granular 設定も調べます。 |
| Side 表示が空になる | モノラルや左右が同一の信号には Side 成分がありません。Stereo を選ぶと合成エネルギーを確認できます。 |
| グラフが止まる、または空に見える | 音声コールバックが続いているか、該当する表示が見えているか、スペクトラムを再表示したか確認します。非表示時やエディターを閉じたときは、表示用の取り込みを意図的に停止しますが、音声処理は続きます。 |
| ルーティングに効果がない | 有効スイッチ、ソースの有無、Depth、宛先の利用可否、Depth via のマクロがゼロでないかを確認します。外部 ENV には実際のサイドチェイン信号が必要です。 |
| MIDI Learn が反応しない | ホストの MIDI ルーティング、形式の対応、チャンネル、実際の送信メッセージ種別を確認します。Learn は MIDI CC を待ち受けます。 |
| LFO カーブを編集しても変わらない | Playback の Wave モードを確認します。Random Hold/Glide は保存したカーブや Smooth ではなく、ランダム生成器を使用します。 |
| 貼り付けが拒否される | 貼り付け先には互換性のある空きスロットが必要で、コピー元の構成を保持できなければなりません。表示された理由を読み、適切なら設定のみのコピーを試してください。 |
| Match が Play audio または LIMIT と表示する | 使用できる入力/出力のある代表的なフレーズを送ります。補正の上限は ±18 dB です。 |
| CPU 負荷が増える | 同じフレーズを HQ オフで比較し、不要な重いエフェクトの数を減らし、解析表示を閉じる/折りたたみます。ホストのバッファーサイズがセッションに適しているか確認します。 |

HQ は追加 Shape を含む Shape 処理に 4x オーバーサンプリングを適用します。負荷はサウンドと動作中のエンジン数に依存します。テープなどの非線形モデルは、単純なデジタル Shape より重い場合があります。すべてのコンピューター、サンプルレート、バッファーサイズ、プリセットに有用な単一の CPU 使用率はありません。同じ条件で比較し、聴感上の効果が必要な場所で HQ を使ってください。解析表示を折りたたむと描画負荷は下がりますが、音声エフェクトが無効になったり、ディレイ/リバーブの残響が凍結されたりはしません。

再現可能な報告には、診断情報、プリセットまたは最小限のチェーン、操作の順序、期待した結果、実際の結果を含めてください。新しく作ったインスタンスや、プロジェクトを開き直した後でも発生するかを記載します。

### キーボードとポインター操作

これらのショートカットは、Fire のインターフェースにフォーカスがあるときに使います。DAW や入力中のテキスト欄では、同じキーが別の動作をする場合があります。

| 操作 | 方法 |
| --- | --- |
| 元に戻す | Cmd/Ctrl-Z、または Menu > Undo |
| やり直す | Cmd/Ctrl-Shift-Z、対応するプラットフォームでは Ctrl-Y、または Menu > Redo |
| 前後のプリセットを試聴 | ライブラリー検索欄にフォーカスがない状態で Up/Down |
| ライブラリーから戻る | Escape、Back to Reactor、またはプリセットのダブルクリック |
| マクロ名を変更 | 名前をダブルクリック。Enter で適用、Escape でキャンセル |
| マクロ値をリセット | マクロノブをダブルクリック |
| LFO ポイントを追加/削除 | Edit モードで空白/削除可能なポイントをダブルクリック |
| LFO ポイントをスナップ | macOS は Cmd、Windows は Ctrl を押しながらドラッグ |
| LFO ポイントを複数選択 | Shift を押しながら選択矩形をドラッグ |
| 対象のオプションを開く | 対応するノブ、モジュール行、LFO エディターを右クリック |
| モジュールのドラッグをキャンセル | Escape、またはチェーンの外にドロップ |
| 選択バンドを分割 | スペクトラム背景にフォーカスがある状態で Return または + |
| 選択バンドを削除 | スペクトラム背景にフォーカスがある状態で Delete/Backspace |
| 検出信号を試聴 | Listen を押し続ける。Listen にフォーカスがあれば Space/Return を押し続ける |

### 本書で使う用語

| 用語 | Fire での意味 |
| --- | --- |
| Band | 周波数領域と、その処理チェーン。 |
| Master | バンドの信号を再合成した後のチェーン。 |
| Module / insert | チェーン内の 1 つのプロセッサー。追加インスタンスはそれぞれ独立しています。 |
| 基準値 | 内部モジュレーションを加える前のノブの値。ホストオートメーションで動かせます。 |
| モジュレーションソース | LFO、エンベロープ検出器、マクロ、MIDI CC の信号。 |
| Depth | ソースが宛先に与える寄与の量と符号。 |
| 正規化範囲 | コントロール内部の 0-1 の位置。Hz、ms、dB に対して線形とは限りません。 |
| A/B サウンドメモリー | ヘッダーで選ぶ、比較用の完全な 2 つのサウンド。 |
| パラレルブランチ A/B | 1 つの Band または Master チェーン内にある、同時に動作する 2 つの経路。 |
| Mid / Side | ステレオ音声の中央 `(L+R)/2` と差 `(L-R)/2` の成分。 |
| Freeze | Granular の録音を保持し、グレインの再生は続ける機能。 |
| 未処理のフリーズ WAV | 後段のグラニュラー演奏やエフェクトを含まない、保存された録音。 |
| HQ | 高レートの Shape 処理経路。Granular の録音容量は増えません。 |
| レイテンシー補正 | ホストがプラグインの遅延を他の経路と揃える処理。 |

### 本版についてとサポート

本書は 2.1.0 の開発実装に対する操作ガイドです。以前のリリースに同じ機能があることを保証するものではありません。新しいプリセットは古い Fire では読み込めない場合があります。制作セッションを別のバージョンへ移す前に、重要な元のプリセットとプロジェクトのコピーを保管してください。

標準モジュールと独立して追加したモジュールには、範囲や互換動作が異なる場合があります。本書では操作に影響する相違点を明示しています。アナログの色付けはモデルと創造的なプロセッサーであり、特定のハードウェア機種と完全に同じであることを保証しません。Fire にギターキャビネット/マイクシミュレーターは含まれません。

スクリーンショットは、生成したデモ音声と分離したプリセットライブラリーを使い、実際の製品コンポーネントで描画しました。ユーザーのセッションや録音した演奏は含まれていません。製品ソースの参照は **9ea20d2** で、Master/追加 OTT の表示修正を含みます。
