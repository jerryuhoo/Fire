## 01. 入门

本手册介绍**开发中的 Fire 2.1.0**，涵盖扩展调制系统、动态均衡器、并联效果链、采样导入与导出，以及统一的 OTT 显示界面。手册于 **2026 年 10 月 24 日**编写，以产品源码提交 **9ea20d2** 为依据。可在 **Menu > Settings** 中查看宿主实际加载的版本。公开下载的版本可能尚未包含本手册中的部分功能。

示例采用当前插件的真实界面截图，音频由演示信号生成。截图中的设置用于说明操作，并非经过校准的预设，也不是必须采用的参数值。大多数插图使用 Ink 皮肤；Vintage 用于展示硬件风格的界面。皮肤外观不会改变声音。

### 安装并加载 Fire

Fire 提供可由兼容宿主加载的插件格式。请选择 DAW 支持的格式；Audio Unit 仅适用于 macOS。复制插件时，请保持插件包的完整性。

| 平台 | 格式 | 常用安装目录 |
| --- | --- | --- |
| macOS | Audio Unit | `~/Library/Audio/Plug-Ins/Components/` |
| macOS | VST3 | `~/Library/Audio/Plug-Ins/VST3/` |
| macOS | CLAP | `~/Library/Audio/Plug-Ins/CLAP/` |
| Windows | VST3 | `C:\Program Files\Common Files\VST3\` |
| Windows | CLAP | `C:\Program Files\Common Files\CLAP\` |
| Linux | VST3 | `~/.vst3/` |
| Linux | CLAP | `~/.clap/` |

1. 从 [Fire 官方发布页面](https://github.com/jerryuhoo/Fire/releases)下载适合的构建版本。核对软件包标明的操作系统和处理器架构。本地开发构建可能只支持编译它的电脑所使用的架构。
2. 替换现有安装前，请先关闭 DAW。将所需格式的插件复制到对应插件目录；用户目录不存在时，可自行创建。Windows 的系统目录可能需要管理员权限。
3. 重新启动 DAW，并按需重新扫描插件。在**音频效果器**中查找 **Fire**；如果宿主按厂商分类，请查找 Blue Wings Music。
4. 将 Fire 插入音频轨道、软件乐器之后，或音频母线上。确认轨道已连接到可听见的输出。
5. 打开 Settings，确认加载的版本。如果仍显示旧版本，先检查宿主选用的插件格式和搜索目录，再决定是否需要重新复制。

在 macOS 上，下载的开发版或采用 ad-hoc 签名的构建可能需要通过系统安全授权。请遵循发布说明中的签名指引和操作系统提示。如果插件包验证失败，请重新获取完整的官方副本；修改插件包内部文件会使签名失效。

### 五分钟上手

Fire 是音频效果器，需要输入音频信号：请将它放在软件乐器之后、音频轨道上，或接收音频的母线上。仅输入 MIDI 音符不会让它发出乐器声音。当宿主将 MIDI 发送给插件时，MIDI 可以用于控制调制。

1. 播放或循环一段同时包含较轻和较响片段的音频，先把监听音量调到舒适的水平。
2. 点击 Fire 顶栏中的预设名称，打开全屏 **Sound Library**。选择 **Analog Drive** 分类，再点击 **Valve Bloom**、**Tweed Touch**、**Iron Program Bus** 或 **Tape Studio Print** 等预设。单击即可加载预设，预设库会保持打开。
3. 点击 **Back to Reactor**。Fire 会选中该预设对应的 Shape 页面；有些预设将音色处理级放在 Master Lab 中，另一些则使用一个或多个频段。
4. 转动工作区标签附近的四个宏旋钮。在 Analog Drive 预设中，它们分别命名为 **Drive**、**Tone**、**Output trim** 和 **Dry blend**。这些名称描述的是当前预设的宏映射，并不代表额外添加了四个效果处理器。
5. 打开 **Match**，播放约三秒钟的循环，等待补偿值出现。这样可以在比较音色时，减少输出音量变大造成的主观偏好。
6. 按 **Copy**，切换 **A/B**，然后编辑另一份声音状态。点击 Match 的数值/Learn 控件，再播放同一段音频，以学习新的补偿值。切换 A/B 比较两种声音。
7. 点击 **Save**，将结果保存为用户预设。如果还需要保留项目中的比较设置、参数锁定和完整宿主会话，请同时保存 DAW 工程。

## 02. 界面与频谱

顶栏提供 A/B 比较、Copy、Match、预设名称、前后切换按钮、Save、应用菜单和 HQ。上方频谱显示输入与处理后的音频，同时提供频段编辑功能。频谱下方的三个工作区用于组织各类控件。

| 工作区 | 用途 |
| --- | --- |
| **Band Lab** | 编辑当前所选频段的效果链，以及该频段的 Output 和 Mix。 |
| **Mod Forge** | 编辑 LFO 形状、播放行为和 MIDI 配置，并打开调制矩阵。 |
| **Master Lab** | 编辑所有频段合并后信号所经过的效果链。 |

每个音频工作区都有一个 **CHAIN** 侧栏。点击某一行即可打开对应模块。处理模块旁的小开关用于启用或停用模块，其外观随皮肤变化。原生 Band Shape 在 Serial 模式下存在一项兼容性例外，详见第 06 章。将鼠标悬停在某一行上，或让该行获得焦点，即可显示 **-** 移除控件。使用 **+** 添加模块，使用 **...** 进行效果链复制、粘贴和文件操作。显示 **Stereo**、**Mid** 或 **Side** 的紧凑按钮用于打开 Routing。

四个宏控件位于工作区标签旁，便于随时调整。宏的数值和名称随声音保存。双击宏名称可重命名，按 Enter 应用，按 Escape 取消。名称最多 32 个字符；留空会恢复为“Macro 1”等默认名称。双击宏旋钮会将数值归零。重命名不会改变该宏在 DAW 中的自动化标识。

当图表提供 **VIEW** 菜单时，**Auto** 会根据当前模块自动选择显示内容。也可以手动选择 Waveform、Transfer、Meters 或 Stereo，观察同一信号的不同特征。例如，调整失真时可查看传输曲线，判断电平变化时则可选择 Meters。OTT 使用专门的 **LIFT / PRESS** 显示，包括在 Band 和 Master 中独立新增的 OTT 实例。点击展开图标可放大图表；点击恢复图标可回到正常控件布局。

### 频谱控件与频段编辑

点击频谱某个频段的下半部分，可将其选中并在 Band Lab 中编辑。点击频谱顶部条带中的目标频率位置，可创建分频点，最多形成四个频段。拖动分频线可改变频率，也可以编辑其频率读数。频段开关和 **S** 控件分别用于旁通或独奏单个频段。频段的移除控件可删除该频段；至少需要保留一个频段。

当焦点位于频谱背景本身时，按 **Return** 或 **+** 可拆分所选频段，按 **Delete** 或 **Backspace** 可移除该频段。如果焦点位于频率输入框等子控件中，这些命令不会生效。

紧凑频谱工具栏集成了声道选择、展开/恢复和折叠控件。闲置时工具栏会变为半透明；鼠标悬停、键盘焦点进入或菜单打开时，会恢复为完整可见。折叠频谱可在三个工作区中释放更多空间。工作区控件旁的小型恢复按钮可重新显示频谱。

| 频谱模式 | 测量内容 |
| --- | --- |
| **Left / Right** | 单个输入/输出声道。 |
| **Stereo** | 两声道合并后的能量；反极性声道不会相互抵消。 |
| **Mono** | `(L + R) / 2`，包含单声道求和产生的抵消。 |
| **Side** | `(L - R) / 2`，用于观察立体声差异。 |

此选项仅改变显示。如果要改变音频处理方式，请在效果链的 Routing 中选择声道。左右完全相同的音频在 Side 中会消失；左右极性相反的音频在 Mono 中会消失，这属于正常现象。如果信号仅出现在一个声道，Stereo 读数比该声道单独显示时低约 3 dB，Mono 和 Side 则低约 6 dB。

### 读懂控件

旋钮数值可能只在拖动、获得焦点或编辑时显示，而非始终可见。工具提示会说明控件用途。调制会添加与调制源颜色对应的范围标记和移动指示；基础值与调制后的数值是两个不同的概念。全屏图表按钮会放大当前视图，并暂时隐藏其下方的控件。收起视图后，这些控件会重新显示。

编辑器保持 2:1 宽高比，支持从 1000 x 500 到 2000 x 1000 的尺寸。拖动窗口角落可调整大小；较大的窗口能为参数标签和图表细节提供更多空间。

## 03. 预设与 Sound Library

点击预设名称可打开 Sound Library。左侧是分类，右侧是具体预设。出厂预设库共有 236 个预设：Vocals、Synths、Drums、Bass、Guitar、Keys、Spaces、Lo-Fi、Rhythm 和 Effects 各 20 个，Analog Drive 另有 36 个。用户预设显示在 **User** 中。出厂预设适合作为起点；编辑后请另存为用户预设。

在搜索框中输入文字，可按预设的描述信息筛选。点击某一行即可立即试听。双击该行、点击 **Back to Reactor** 或按 Escape，可返回处理界面。搜索框未获得焦点时，使用上/下方向键可试听相邻预设。当前声音保持高亮显示。顶栏的前/后箭头也可以逐个切换预设。

编辑器会在操作过程中记住当前分类、搜索内容和滚动位置。**Recent** 最多保存 24 个最近试听过的预设。**Locate current** 会清空搜索，并在对应分类中显示当前播放的预设。最近记录和浏览位置仅用于当前会话，不会写入声音文件或 DAW 工程。

### 收藏、隐藏与恢复

点击预设旁的星形图标，可将其加入 **Favourites** 或取消收藏。收藏记录保存在本地预设库中。预设移除控件的行为取决于预设来源：

| 预设类型 | 移除操作 | 恢复方式 |
| --- | --- | --- |
| 用户预设 | 将文件移入 Fire 的 **Recycle Bin**。 | 恢复到原有分类。 |
| 出厂预设 | 隐藏对应出厂条目。 | 从 Recycle Bin 恢复隐藏的预设。 |

恢复预设不会自动加载它，也不会覆盖已有的用户文件。因此，移除预设条目与初始化当前声音是不同的操作。需要回到初始声音状态时，请使用 **Menu > Init**。

### 标签与描述

![预设详情可用于编辑描述性标签和备注；对出厂预设的修改会作为本地元数据覆盖保存。](images/21-preset-details.png)

选中预设后，点击铅笔/编辑详情图标，可修改标签和描述。用逗号分隔标签；如果标签本身包含逗号，请将该标签用引号括起来。Fire 最多接受 16 个标签，每个标签最多 32 个字符，描述最多 2,048 个字符。

用户预设的这些信息保存在其 `.fire` 文件内。编辑详情会保留音频设置及任何已冻结的录音。覆盖保存预设会保留其备注；另存新版本时，则会继承所选声音的备注。对出厂预设的修改属于个人预设库的覆盖信息：点击 **Restore original** 可恢复原始标签与描述。要编辑已归档用户预设的详情，请先将其恢复。如果详情编辑器打开期间文件发生了变化，请重新打开详情后再保存。

### 浏览预设时保留指定数值

> 多个模块具有同名控件时，建议通过目标旋钮的右键菜单锁定具体数值。锁定会在加载声音时保留基础值；它不会冻结输入音频、停用调制，也不会自动锁定整个模块。

预设参数锁定可在加载或依次切换整个插件的预设时，保留指定的**旋钮基础值**。例如，试听不同声音时，可以保持某个 Output 或 Mix 数值不变。

1. 右键点击支持锁定的旋钮，选择 **Keep value when loading presets**。也可以打开 **Menu > Preset parameter locks...**。
2. 在锁定窗口中搜索参数，并勾选需要保留的项目。**Locked only** 只显示当前已锁定的参数；**Unlock all** 可清除所有锁定。
3. 加载另一个预设。已锁定的基础值将保留。由于当前声音可能不同于已保存的预设，名称旁可能会出现正常的 `*` 已修改标记。

![预设锁定管理器列出了可用控件。多个模块名称重复时，右键点击目标旋钮是确认锁定对象最清楚的方式。](images/20-preset-locks.png)

锁定不会阻止手动编辑、宿主自动化或调制。新预设中的调制路由与源定义仍会加载，因此已锁定的基础值仍可能受到调制。结构性设置，包括频段数量、分频点、模块的存在与顺序、路由模式和分支分配，均不能锁定。锁定偏好属于实例的工程状态，不属于 `.fire` 预设。A/B 切换、撤销/重做和工程恢复会还原完整状态，而不会套用浏览预设时的锁定规则。

### 不同内容保存在哪里？

| 保存位置 | 主要内容 |

## 04. A/B、响度 Match 与编辑历史

顶栏的 **A/B** 用于切换两份完整声音状态。**Copy** 会将当前一侧复制到另一侧。这与并联效果链内部的 **A/B 分支**不同：声音状态用于比较整套设置，而分支会同时处理音频。

要进行等响度比较，请为两份状态循环播放同一段具有代表性的音频。启用 **Match**，让当前一侧学习约三秒钟。切换 A/B，再让另一侧学习。每一侧都会保留各自固定的 dB 补偿值。Copy 也会复制该补偿值。

点击数值/Learn 控件可重新测量；测量期间再次点击可取消。关闭 Match 可听到未经补偿的电平。Match 不会移动 Output，也不会改动其自动化。宿主旁通会直接传递旁通信号，并暂停学习。

显示 **Play audio** 表示测量未获得足够的有效输入与输出；此前有效的结果会保留。显示 **LIMIT** 表示所需补偿超出了可用的 ±18 dB 范围。Match 用于短时试听比较，并非综合 LUFS 测量仪。编辑过程中其补偿保持固定，因此进行较大改动后应重新学习。加载声音预设会清除该侧的测量结果；如果 Match 仍处于启用状态，它会重新学习。Match 状态和学习得到的增益保存在工程中，独立于 `.fire` 文件。

### 撤销与重做

使用 **Menu > Undo / Redo**、**Cmd/Ctrl-Z**、**Cmd/Ctrl-Shift-Z** 或 **Ctrl-Y**。撤销会将一次常规旋钮操作、模块复制或效果链替换等操作归为有意义的编辑步骤。它也覆盖 LFO 形状、路由、EQ 节点和冻结素材的修改。关闭并重新打开编辑器后，历史记录仍可使用；加载 DAW 工程则会重新开始记录。音频线程自动化不会为每次参数更新都创建一条撤销记录。Fire 在 64 MiB 快照预算内最多保留 100 次编辑；撤销不会改变当前编辑器尺寸。

## 05. 效果链、并联路由与 Mid/Side

Fire 将输入划分为一到四个频率区域。所选 Band 效果链处理对应区域；各频段输出合并后，再交给 Master 效果链处理。

```text
输入 -> 分频 -> 各 Band 效果链 -> 合并 -> Master 效果链 -> 输出
                  |  |  |  |
                 最多四个频段
```

Band Lab 与 Master Lab 共用 Drive、Shape、Compressor、OTT、Stereo、EQ、Lo-Fi、Chorus、Flanger、Phaser、Delay、Reverb、Granular 和 Chord Resonator。原生模块与新增模块一样，可以移除后重新添加。每条效果链最多有八个额外的独立插入槽位。Analysis 是 Master 中可移除的显示页面，不处理音频。

点击 **+** 并选择模块。点击模块所在行可编辑它。拖动该行的名称或主体区域可调整顺序，插入线会预览新位置。拖动时停留在侧栏边缘附近，可滚动到当前不可见的行。松开鼠标即可确认。按 Escape、拖放到侧栏外，或切换工作区/频段，都会取消拖动。重排会保留模块的参数和路由。音频模块按列表顺序处理信号，Band Output/Mix 位于该频段效果链之后。

### 串联、并联与中置/侧向处理

![Routing 面板集成了声道选择、Serial/Parallel 模式、分支分配和 Blend。每条分支均使用当前效果链已有的模块。](images/13-routing-detail.png)

点击 CHAIN 旁紧凑的 Stereo/Mid/Side 按钮，可打开 Routing。

| 控件 | 作用 |
| --- | --- |
| **Serial** | 模块依次串联处理。 |
| **Parallel A/B** | 两条分支接收同一个效果链输入，再混合各自的输出。 |
| **To A / To B** | 将模块移到另一条分支。模块行菜单中也提供 **Move to Branch A/B**。 |
| **Up / Down** | 调整模块在分支内部的顺序。 |
| **Blend** | 分支 B 的占比：0% = 仅 A，100% = 仅 B。 |
| **Stereo** | 处理立体声信号。 |
| **Mid** | 处理中置分量，保留原始 Side 分量。 |
| **Side** | 处理侧向差异分量，保留原始 Mid 分量。 |

并联分支共用现有模块槽位，并不会额外生成另一组独立的八槽效果架。空分支会原样传递输入。混合采用线性方式，因此两条分支完全相同时，总体保持单位增益。即使 Blend 位于端点，两条分支也会持续运行，使延迟和混响的历史状态保持更新。分支会在合并前对齐延迟；所在频段或母线的 Output/Mix 位于合并之后。Mid/Side 处理包裹整条效果链，包括两条并联分支。

进行并联压缩时，可将 Compressor 或 OTT 放在 B 分支，让 A 保持为空，再从 0% 开始逐渐提高 Blend，直到细节与密度适合素材。要混合不同音色，可在 A、B 两条分支中分别放置不同的 Shape 模块。Blend 支持常规调制和宿主自动化，可在矩阵中找到 **Routing / Blend**。切回 Serial 后，分支分配和 Blend 数值会保留，以便稍后使用。路由结构和分支分配支持宿主自动化，但不能作为插件内部的调制目标。

选择 Mid 或 Side 后，适用的频段或母线输出控件仅作用于选中分量。立体声效果的输出会重新求平均并归入该分量，避免处理结果泄漏到未处理的另一分量。对于单声道输入，Mid 的行为与 Stereo 相同，Side 则以相同延迟直通。频谱分析器中的 **Side** 仅用于显示差异，不会启用这里的处理模式。

### 复制单个模块

右键点击模块行，或让该行获得焦点后按 **Shift+F10**。

- **Copy settings**：复制模块设置，不包含指向该模块参数的调制路由。
- **Copy with routing**：同时包含上述调制路由。
- **Duplicate settings**：在源模块之后立即插入一份仅含设置的副本。
- **Paste ... after**：将已复制模块插入所选行之后。向空效果链粘贴时，可使用 **+** 菜单中的已复制模块条目。

复制的模块会保留其分支分配，但不会改变目标效果链的路由模式、Blend 或 Stereo/Mid/Side 模式。模块剪贴板与效果链剪贴板彼此独立；在同一进程中，相同插件格式的 Fire 实例可以共享这些剪贴板。

### 复制或保存整条效果链

打开效果链的 **...** 菜单。**Copy chain settings** 或 **Copy chain with routing** 会按顺序复制音频模块。**Paste chain** 仅替换目标效果链；其他频段、Master、分频点、Output/Mix 和全局调制源均保持不变。复制一条空效果链，可用于清除另一条效果链中的音频模块。Analysis 不会被包含在内。

使用 **Save chain preset...** 可保存仅含设置的 `.firechain` 文件；使用 **Save chain preset with routing...** 可同时包含映射。**Load chain preset - replace...** 会用文件中的内容替换当前效果链。效果链文件保存在预设目录中的 **Chains** 文件夹，包含声道/并联路由，以及模型、EQ 节点和冻结音频等模块数据。

“With routing”会复制指向目标参数的映射、范围、曲线，以及调制深度的宏分配。它使用目标实例当前的 LFO、包络、宏和 MIDI CC 配置，不会覆盖这些调制源定义。如果需要完整保留原始声音，请使用整个插件的预设。

Fire 会在修改目标前检查整套粘贴内容能否放入兼容槽位。有些原生模块需要对应的兼容核心实现：原生 Master Lo-Fi 使用不同的引擎；采用 Legacy Link 的 Drive 可能需要原生 Drive 槽位，或转换为 Drive Comp。如果无法完整保留必要的设置或路由，Fire 会说明原因，并保持目标不变。

### 顺序与三个层级的 Mix

顺序同时影响音色和动态。失真前的 EQ 决定哪些频率更强烈地驱动失真；失真后的 EQ 则用于调整已经生成的谐波。失真前的压缩器可稳定驱动电平，失真后的压缩器则控制处理后的信号。将 Delay 放在失真前，可让每次重复与失真相互作用；放在失真后，则重复已经失真的声音。

模块的 **Mix** 通常混合该模块输入与自身处理后的信号。在原生 Band 中相邻的 Drive > Shape 路径下，Shape Mix 会混合整个组合失真级，包括 Drive。**Band Mix** 混合整条频段效果链与该频段的干声；全局 **Mix** 混合整体效果与其干声路径。这些混合比例会叠加：较低的模块 Mix 再接较低的 Band Mix，会让效果变得很轻。**Output** 控制电平，而不是失真量。请使用输出微调来平衡音量，并在修改效果链后重新检查电平。

> 要把某条并联分支作为真正的干声参照，请先移走或删除其中的处理模块。Routing 示例截图中的 A 分支包含模块，并非空的干声分支。原生 Band Shape 在 Serial 模式下保留了一条兼容路径，详见第 06 章。

## 06. Drive 与 Shape

Drive 与 Shape 是 Fire 失真操作的核心。**Drive** 提高进入非线性处理级的电平。**Shape** 选择传输曲线或模拟音色，并调整其不对称性。在原生频段效果链中，相邻的 Drive > Shape 模块使用组合处理路径。将二者分开后，它们会成为独立处理级，因此插在中间的效果会影响送入 Shape 的信号。

![Vintage 皮肤下的 Warm Triode：硬件插图、Shape 局部控件和所选频段。电子管亮度会随输入电平与 Drive 变化。](images/04-vintage-tube.png)

### Drive、Safe 与补偿

| 控件 | 实际作用 |
| --- | --- |
| Drive | 输入增益量，控件刻度为 0-100。通常数值越高，声音越密集、失真越明显，但结果取决于音源和 Shape。 |
| Safe | 根据输入峰值限制实际 Drive，可能使实际施加的驱动量低于旋钮设定值。 |
| Extreme | 大幅增加同一 Drive 设置所能提供的增益。启用时请从较低数值开始。 |
| Gain Comp / Comp | 根据实际使用的驱动量估算电平衰减，便于比较，同时保持 Output 可独立调整。 |
| Output | 对应效果链之后的手动电平微调，不是另一个失真控制。 |

Safe 用于管理驱动量，不是最终母线限幅器。Gain Comp 属于估算，而非响度测量。其动态读数反映实际施加的补偿；无法获取当前音频遥测时，会用近似符号标明估算值。需要实际测量整条效果链的电平差异时，请使用顶栏的响度 Match 流程。

较早的声音可能显示 **Legacy Link**。该模式保留 Drive 与最终 Band Output 之间原有的关联。点击 **Use Drive Comp** 会明确将该频段切换至新的补偿方式，并重新启用已保存的手动 Output 设置，因此声音可能发生变化。在并联效果链中，Legacy Link 会影响最终 Band Output，也就影响两条分支；新的补偿方式则只作用于 Drive。

### Shape 控件

在 Shape 选择器中选择模型。**Bias** 让信号相对于整形曲线发生偏移，以产生不对称性，范围为 -1 至 +1。**Rectification** 改变整形后波形的负半部分：0 保留原有极性，0.5 移除负半部分，1 则将其翻转为正。中间值在这些行为之间混合。Bias 和整流可能引入直流偏移，因此请按需启用 **DC** 或 **DC Filter**。**Mix** 混合整形结果与输入；在原生 Band 中相邻的 Drive > Shape 路径下，它作用于整个组合失真级，包括 Drive。

> **Serial 模式下的原生 Band Shape：**为保持兼容性，关闭该模块时仍会保留选中的失真曲线，但会停用 Bias、Rectification 和 DC 滤波，并忽略已保存的 Shape Mix。移除原生 Shape 行后，Serial 模式也会保留这一行为。因此，Shape 控件变灰并不保证信号完全干净。要进行干声比较，请将 Band Mix 设为零，或旁通整个频段。独立新增的 Shape 使用常规干湿旁通；在 Parallel A/B 模式下，原生 Shape 关闭或移除时，其曲线也会被旁通。

原生 Band 的模拟页面使用该频段的 Drive 控件。独立新增的模拟 Shape 模块拥有各自的 Drive，因此可以在同一效果链中设置多个驱动量不同的音色处理级。在独立模拟 Shape 中，局部 Drive 会直接控制模型；不要将独立 Drive 模块的开关误认为属于该 Shape 实例。

**HQ** 使用更高采样率的失真处理路径，以减少不需要的混叠。对于明亮、强驱动的素材，以及使用折返整形的设置，差异可能更明显。HQ 会增加 CPU 用量，请按实际使用时的质量设置试听。传输图可帮助理解静态波形整形曲线，但无法描述磁性模型或受供电状态影响的模拟模型中所有随时间变化的特征。

### 数字 Shape 模型

![数字 Shape 页面显示传输曲线和不对称性控件。图表展示的是一条曲线，并非模拟模型完整的动态行为。](images/06-shape-panel.png)

| 模型 | 特征与建议起点 |
| --- | --- |
| Arctan | 圆润、逐渐进入饱和的曲线，适合克制的染色。 |
| Exp | 指数软饱和，进入削波的过渡方式有所不同。 |
| Tanh | 平滑、对称的饱和，适合通用的增厚处理。 |
| Cubic | 圆润的多项式削波，也是默认数字模型。 |
| Hard | 在曲线极限处突然削波，产生较强的高次谐波。 |
| Sausage | 较为坚实的曲线，接近削波处的转角经过软化。 |
| Sin | 重复的正弦折返；提高 Drive 可能带来复杂变化，而不仅是更多削波。 |
| Linear | 类似三角波的折返，转折更有棱角。 |
| Limit | 将信号削波到较窄的电平范围。选择后请凭听感补偿电平。 |
| Single Sin | 使用单个正弦形区域，并抑制该区域之外的样本；高 Drive 时可产生特殊质感。 |
| Logic | 保留的历史选项，当前稳定传输曲线与 Tanh 等效。 |
| Pit | 带有高电平减法分量的饱和曲线，适合不常规的高驱动动态变化。 |

这些名称描述 Fire 提供的曲线，并不承诺复现某款商业失真处理器的音色。进行受控比较时，请将 Bias 和 Rectification 均设为零，每次只选择一条曲线，并在判断前平衡输出电平。

### Analog Hardware 模拟音色

![Tape Saturation 在处理音频时显示转动的磁带传动机构。动画用于反馈所选模型的活动状态。](images/05-vintage-tape.png)

这些模型的音色设计参考了电路机制，但并不是对特定硬件的校准复刻。放大器模型包含供电和工作点行为；Transformer 与 Tape Saturation 包含磁性记忆。它们的响应取决于音频的电平及历史状态，因此持续音与尖锐瞬态不一定产生相同的表现。

| 模型 | 建议用途 |
| --- | --- |
| Warm Triode | 为人声、贝斯或键盘加入温和、不对称的电子管风格暖度。 |
| Bright Pentode | 更靠前的电子管音色，适合需要存在感的素材。 |
| Class A Console | 为单轨或母线加入细微的调音台风格密度。 |
| Tweed Breakup | 柔和、有弹性的吉他风格破音与动态 crunch 质感。 |
| British Crunch | 更强、中频更突出的 crunch 音色，适合吉他和节奏素材。 |
| Modern High Gain | 级联、密集的失真，适合具有攻击性的音色。 |
| Diode Overdrive | 集中的过载音色，适合主奏、贝斯清晰度或鼓组重音。 |
| Germanium Fuzz | 不对称 fuzz，性格较柔和、偏暗。 |
| Silicon Fuzz | 更明亮、坚实的 fuzz，具有明显的高次谐波。 |
| MOSFET Drive | 不对称驱动音色，介于温和饱和与较硬过载之间。 |
| Transformer | 磁性染色，以及受历史状态影响的饱和。 |
| Tape Saturation | 带偏磁的磁记录音色，包含录音/回放与磁头损耗整形。 |

这些描述用于指导试听，并不保证固定的音色结果。Tape Saturation 是通用磁带模型，不提供带速、偏磁或磁头类型选择器。Lo-Fi 中独立的 Tape/Wow/Flutter 控件则服务于另一类效果。

电子管亮度同时跟随输入声音与 Drive，因此仅将 Drive 调高，并不会让无声状态下的电子管发亮。磁带卷盘随音频活动转动，处理停止后会逐渐停稳。图形用于反馈活动状态，并非经过校准的电气仪表。Paper 与 Ink 使用这些显示的线条示意版本，底层声音保持不变。

## 07. Compressor 与 OTT

### Compressor 压缩器

Compressor 按 **Ratio** 设定的比例，压低超过 **Threshold** 的信号。**Attack** 决定增益衰减开始响应的速度，**Release** 决定恢复的速度。较慢的起音通常能保留更多最初的冲击；较快的起音则会捕捉更多初始峰值。可先将 Ratio 设在约 2:1 至 4:1，逐渐降低 Threshold，直到听到压缩效果，再结合节奏调整时间参数。

| 控件 | 原生 Band Compressor | 新增 Compressor 实例 |
| --- | --- | --- |
| Threshold | -48 至 0 dB | -60 至 0 dB |
| Ratio | 1:1 至 20:1 | 1:1 至 20:1 |
| Attack | 0.1-200 ms | 0.1-200 ms |
| Release | 10-2000 ms | 1-1000 ms |
| Mix | 干声至完全处理后的信号 | 干声至完全处理后的信号 |

原生 Band 模块保留历史参数范围；在 Band 或 Master 中新增的实例使用上表的新增模块范围。Ratio 为 1:1 时不会产生压缩。Compressor 没有专用补偿增益旋钮，请使用适当的 Output 控件或效果链安排来恢复电平。降低 Mix 可在模块内部实现并联压缩；也可以使用效果链的并联分支，分别处理干声与压缩信号。

### OTT：抬升轻微细节，压低响亮峰值

原生 Band 模块将阈值标为 **Up Thresh** 和 **Down Thresh**，输出微调标为 **Gain**。独立新增的 OTT 则用 **Up**、**Down** 和 **Output** 表示相同的功能。

OTT 同时使用向上压缩和向下压缩。它会抬高低于 **Up / Up Thresh** 的较轻信号，压低高于 **Down / Down Thresh** 的较响信号，而两者之间的区域受影响较小。频率分离由 Fire 本身的多频段分频完成：单个 Master OTT 处理其完整输入信号，不会在内部另外创建一套分频频段。

![Master OTT 与 Band OTT 使用相同的 LIFT / PRESS 视图。输入、增益变化和动态活动均来自当前选中的 OTT 实例。](images/09-ott-panel.png)

| 控件 | 范围与作用 |
| --- | --- |
| Depth | 总体动态处理强度，从零到最大。原生 Band 显示 0-1，新增实例显示百分比。 |
| Time | 10-400%，同时缩放起音与释放时间。100% 对应 5 ms 起音和 100 ms 释放。 |
| Up / Up Thresh | -72 至 -6 dB，较轻信号的阈值。始终比向下压缩阈值至少低 6 dB。 |
| Down / Down Thresh | -36 至 0 dB，较响信号的阈值。 |
| Output / Gain | -24 至 +24 dB，动态处理之后的电平微调。 |
| Mix | 干声至完全处理后的信号。 |

向上与向下压缩使用固定的 4:1 和 8:1 比率，并具有软拐点。向上增益受到限制，并会在接近噪声底时逐渐消退；OTT 不会凭空生成噪声。两个声道共用检测器和增益，以保留立体声关系。

**LIFT / PRESS** 视图显示所选模块的活动。向上抬起的带状图形表示向上压缩，向下压动表示向下压缩。每个独立新增的 OTT 都有自己的读数，包括 Master Lab 中的实例。动态图形不包含 Output 微调，因此单独转动 Output 并不代表压缩变强。

对于原生 Band OTT，还可以直接调整频谱中的阈值线。上下拖动线条可修改阈值，双击可重置，获得焦点后可用方向键精细调整。建议从适中的 Depth 开始；如果房间声或噪声变得过于突出，请适当减小。Time 低于 100% 时会强化快速响应，较长设置则让变化更缓慢。

## 08. Stereo 立体声

Stereo 包含 **Width**、**Pan** 和 **Mix**。Width 用于改变立体声信号中中置分量与差分分量的比例。原生 Band 模块的中性位置为 **0.50**，新增模块则为 **50%**。较低的设置偏重中置分量，较高的设置偏重侧向分量。调至两端时，另一种分量会被移除，因此 100% 并不只是“将普通立体声拓宽到最大”。

Pan 向左或向右移动时，会衰减另一侧声道。Mix 将立体声处理结果与模块输入混合。拓宽需要信号本身包含立体声信息：没有差分分量的居中信号，无法仅靠 Width 产生独立的侧向细节。单声道处理总线会旁通这一立体声处理。

使用较大的宽度时，可将频谱显示设为 **Mono**，并实际用单声道监听对比。强调差分信号来拓宽立体声，可能使单声道叠加后的音量明显降低。此时可减小 Width、降低模块 Mix 以保留更多干声，或让低频段的宽度更接近中性位置。

## 09. EQ 与动态均衡

每个 EQ 最多支持 **12 个频点**。选中带编号的频点后，可编辑其 **Frequency**、**Gain**、**Q**、**Filter Type**，以及适用时的 **Slope**。用 **+** 添加频点，用 **-** 删除频点。每个频点都有独立的开关。模块旁通时仍可编辑 EQ；添加频点会启用模块，便于试听。

![Master EQ：频谱上的频点与所选频点的控件。通过频点导航和类型菜单，编辑目标滤波器。](images/07-master-eq.png)

### 静态 EQ

| 类型 | 用途 |
| --- | --- |
| Bell | 提升或衰减所选频率附近的内容。 |
| Low cut | 移除截止频率以下的低频内容。 |
| High cut | 移除截止频率以上的高频内容。 |
| Low shelf | 调整较宽的低频区域。 |
| High shelf | 调整较宽的高频区域。 |
| Notch | 移除狭窄的频率区域；Gain 不可用。 |
| Band pass | 保留中心频率附近的区域；Gain 不可用。 |

Low cut 和 High cut 提供 **12、24、36 或 48 dB/oct** 的斜率。Q 控制带宽或共振程度。Gain 范围为 -24 至 +24 dB。Frequency 范围为 20 Hz-20 kHz，实际可用的频率响应还取决于宿主采样率。新增 EQ 模块的频点提供 0.1-20 的 Q 范围。原生 Master EQ 的前三个频点保留 1-5 的 Q 范围，后续频点的 Q 范围则为 0.1-18。

原生 Master EQ 还支持直接在频谱上编辑。在频谱空白处双击，可在该位置添加 Bell 频点；拖动频点可改变频率和增益，在频点上滚动鼠标可调整 Q。当该频谱获得焦点时，按 Delete/Backspace 可删除所选频点。这些操作属于 Master EQ 编辑视图，不要与在频段频谱上添加分频点的操作混淆。

### 动态 EQ

![动态控件针对当前选中的 Bell 或 Shelf 频点。Range 决定增益变化的方向及最大幅度。](images/08-dynamic-eq.png)

选择 **Bell**、**Low shelf** 或 **High shelf**，然后在频点标题栏打开 **Dynamic** 并启用。其他滤波器类型不提供动态处理。

| 控件 | 含义 |
| --- | --- |
| Threshold，-60 至 0 dB | 电平高于此阈值时，检测器开始请求增益变化。 |
| Ratio，1:1-20:1 | 控制随电平变化的响应强度；1:1 时不产生变化。 |
| Range，-24 至 +24 dB | 带方向的最大增益变化量：负值衰减，正值提升。 |
| Attack，0.1-200 ms | 对电平升高作出响应的速度。 |
| Release，5-2000 ms | 恢复速度。 |

检测器监听 EQ 模块的原始输入，对该频点频率附近的信号进行滤波，并取左右声道中较高的峰值。它不是外部侧链选择器，也不会串联接收同一 EQ 中前面频点处理后的信号。基础 Gain 与动态增益之和保持在 ±24 dB 以内。

播放音频时，可观察动态增益变化量和实际增益读数。原生 Master EQ 的实时曲线会跟随实际增益变化，但可拖动的频点和 Gain 旋钮仍保留基础设置。动态参数支持宿主自动化、预设、参数锁定和链路复制；它们不能作为 Fire 内部调制的目标。Frequency、Gain 和 Q 仍支持常规调制。

## 10. Chorus、Flanger 与 Phaser

这些效果通过各自内部的周期性扫动，为声音增加运动感。Rate 旋钮以赫兹为单位；不要将这些内部振荡器与独立的 LFO 库混淆。Fire 的调制系统仍可改变这些效果对外提供的控制参数。

| 效果 | 控件与范围 |
| --- | --- |
| Chorus | Rate 0.05-8 Hz；Depth 0-100%；Delay 5-30 ms；Feedback -75 至 +75%；Width 0-100%；Mix 0-100%。 |
| Flanger | Rate 0.05-8 Hz；Depth 0-100%；Delay 0.1-10 ms；Feedback -90 至 +90%；Width 0-100%；Mix 0-100%。 |
| Phaser | Rate 0.05-8 Hz；Depth 0-100%；Center 40-6000 Hz；Feedback -85 至 +85%；Width 0-100%；Mix 0-100%。 |

Chorus 用不断变化的短延迟增厚声音，并产生音高运动。Flanger 使用更短的扫动延迟，与干声混合时形成带金属感的梳状响应。Phaser 使用六级全通滤波链，让移动的凹陷频段形成较圆润的扫动感。

Depth 设置扫动幅度。Chorus/Flanger 的 Delay 设置中心延迟时间；Phaser 的 Center 设置扫动所在的频率区域。Feedback 增强共振，负值会带来不同的音色。Width 改变两个声道之间的扫动偏移，设为零时两侧扫动对齐。Mix 决定干声与处理信号如何相互作用。

若希望听到明显的 Flanger/Phaser 相消效果，可从约 50% Mix 开始。较慢的 Rate 和适中的 Depth 适合铺底音色；较快的 Rate 可让打击乐或键盘更有动感。100% 湿声时，由于干声不再参与相消，音色可能明显不同。

## 11. Delay 延迟

Delay 提供 **Time**、**Feedback**、**Tone**、**Ping-Pong**、**Sync** 和 **Mix**。Sync 设为 **Free** 时，Time 范围为 **10-2000 ms**。同步选项为 **1/16、1/8、1/8 D、1/4、1/4 D、1/2 和 1 Bar**，其中 D 表示附点。同步延迟跟随宿主速度，但受两秒延迟容量限制。宿主速度较慢时，较长的时值可能达到这一上限，无法实现完整的标称时长。

Feedback 范围为 0-90%，控制回声的重复程度。Tone 范围为 500 Hz-18 kHz，对反馈路径进行滤波：值越低，后续回声越暗。Ping-Pong 范围为 0-100%，从普通立体声延迟逐步变为在两个声道之间交替的延迟。Mix 设置回声相对于干声输入的比例。

制作人声短回声时，可使用 Free 模式，将 Time 设为约 80-130 ms，并采用较低的 Feedback 和较小的 Mix。制作节奏性运动时，可选择附点八分音符和适中的 Feedback；如果回声与原声争抢空间，再降低 Tone。在专用返回轨上，可从 100% Mix 开始；作为插入效果时，建议从低得多的 Mix 开始。

## 12. Reverb 混响

可选择 **Classic、Room、Hall、Plate、Spring 或 Chamber**。它们共用相同的六个控件，比较不同模型时不必重新熟悉另一套面板。

![新增 Reverb 模块提供算法菜单，以及 Size、Damping、Pre-delay、Width、Low Cut 和 Mix。](images/10-reverb-panel.png)

| 控件 | 含义 |
| --- | --- |
| Size，0-100% | 改变空间与衰减特性；它不是经过标定的衰减时间读数。 |
| Damping，0-100% | 数值越高，循环反馈的混响尾音越暗。 |
| Pre-delay，0-200 ms | 混响信号出现前的延迟，有助于将声源与尾音分开。 |
| Width，0-100% | 混响的立体声扩展程度。 |
| Low Cut，20-1500 Hz | 移除进入混响的低频能量。 |
| Mix，0-100% | 干声与混响的比例。 |

**Classic** 保留 Fire 原有的混响特性。**Room** 适合从紧凑的环境感和可辨识的早期反射入手。**Hall** 适合更宽广、随时间展开的空间。**Plate** 能为人声、军鼓或持续音构建密集的尾音。**Spring** 带有色散感和弹簧式音色，适合吉他与声音设计。**Chamber** 提供另一种早期反射与衰减结构，质感介于贴近与宽阔之间。这些都是算法混响，不是对特定房间或硬件进行卷积采样的结果。

切换模型时，插件会在经过干声的淡变过程中清除前一模型的延迟历史，因此不要期待旧尾音原样延续。若要提高人声清晰度，可先尝试增大 Pre-delay 和 Low Cut，再考虑直接降低 Mix。若要保留鼓的冲击力，可选择听感更短的 Size，少量加入混响，或将它放在并联分支上。

## 13. Lo-Fi 低保真

Lo-Fi 将采样率降低、量化和磁带式运动结合起来。**Rate** 是降采样倍数：数值越大，采样保持的时间越长，声音也越粗糙，更有低采样率质感。**Bits** 降低振幅分辨率。**Jitter** 改变采样保持的时序，并非额外加入一条噪声轨。

**Tape** 增加饱和并柔化高频。**Wow** 增加缓慢的音高漂移，**Flutter** 增加较快的变化。**Mix** 混合完整的 Lo-Fi 处理结果。可先将 Tape/Wow/Flutter 设为零，清楚地听辨降采样与位深降低的效果，再逐项添加音色变化。

原生 Master Lo-Fi 保留 **1-64** 的 Rate 范围和 **4-32** 的 Bits 范围。新增 Lo-Fi 模块使用 **1-32** 的 Rate 范围和 **4-24** 的 Bits 范围，Tape、Wow、Flutter 和 Jitter 均可从零调至最大。原生控件可能显示归一化的 0-1 数值，而新增模块以百分比显示；它们在声音设计中的作用相同。

制作老化的键盘音色时，可采用轻度降采样、较高的 Bits、少量 Tape 和缓慢的 Wow。制作粗粝的鼓声时，可先降低 Bits，再提高 Rate 和 Jitter，直到起音呈现所需的颗粒感。Lo-Fi 中的 Tape 是简洁的染色控制；专用的 **Shape > Tape Saturation** 则采用更细致的磁性模型。

## 14. Chord Resonator 和弦共振器

Chord Resonator 用输入音频激励一组经过调谐的谐波共振单元。它尤其适合打击乐、噪声及谐波丰富的素材。它不会识别歌曲的调性，也不会把任意音符重新调音到某个音阶。

**Root** 可选 **C2 至 C5**；**Chord** 可选 **Major、Minor、Major 7、Minor 7、Sus 2、Sus 4、Fifth 或 Octave**。音符读数显示和弦配置。在 Fire 的命名中，中央 C 为 C4。

**Color** 调整基音与高次谐波的比例。**Decay** 设置标称衰减 60 dB 所需的时间，范围为 **0.05-3 秒**。**Width** 将各声部分散到立体声空间中；设为零时，每个声部的左右权重相同，同时保留输入信号的立体声声道。**Mix** 平衡声源起音与持续共振的和弦声。

可在打击乐循环上从默认的 C3 Minor 7、适中的 Decay 和较低的 Mix 开始。选择与歌曲相符的 Root。如果希望低频基音保持直接，可将它放在中高频段。不需要 MIDI 输入，激励信号来自音频。没有新的输入音频时，只会继续播放已有尾音。

## 15. Granular、Freeze 与采样文件

Granular 使用 Fire 改编的 Mutable Instruments Clouds **普通粒子模式**。它将输入音频录入短时滚动缓冲区，再重叠播放其中的声音片段。引擎采用 **32 kHz、立体声、16-bit** 音频，并在输入与输出时转换至宿主采样率。这是其音色的一部分；透明的干声信号则单独保留。

![展开的 Granular 页面包含 Clouds 控件、Freeze，以及进入 Sample 的入口。](images/11-granular-panel.png)

### 粒子控件

| 控件 | 操作 |
| --- | --- |
| Position | 选择录音中的位置；顺时针转动会移向更早的音频。 |
| Size | 粒子长度控制，范围为 0-100%。 |
| Pitch | 将粒子移调 -24 至 +24 个半音。 |
| Density | 负值一侧规律地安排粒子，正值一侧随机安排粒子；中心位置不产生新粒子。 |
| Texture | 从较锐利的粒子包络逐渐变为较平滑的包络；较高设置增加扩散。 |
| Spread | 粒子在立体声空间中的分布。 |
| Feedback | 将粒子处理的输出反馈至处理路径。 |
| Reverb | 添加 Clouds 引擎自身的混响。 |
| Mix | 输入干声与粒子处理输出的比例。 |
| Freeze | 停止更新录音，粒子则继续播放。 |

如果启用 Freeze 后没有声音，请确认已有录音、Density 不在中心位置，且 Mix 大于零。Freeze 保留的是素材，并不会自动将每个粒子或混响尾音都固定在完全相同的状态。录音为空时，模块会先捕获新的音频，再将其冻结。

### 捕获实时音色

1. 关闭 Freeze，让一段短素材通过 Granular 模块播放。
2. 将 Density 调离中心，并将 Mix 提高到能听清粒子的程度。
3. 在想要保留的时刻按下 **Freeze**。
4. 冻结素材继续播放时，尝试调整 Position、Size 和 Pitch。
5. 加入适量 Feedback 或 Reverb，让音色更持久。
6. 保存预设或宿主工程，将冻结录音与音色一同保存。

完成捕获的冻结录音会嵌入预设、工程状态、A/B 快照和可移植的模块/链路文件。重新加载时会恢复录音，包括其立体声内容和环形缓冲区位置；已安排的粒子以及延迟/混响历史则会重新开始。冻结音色要继续播放，宿主必须持续处理音频。

### 导入文件

点击 Freeze 旁的 **Sample**，打开 **Granular / Sample**，再点击 **Choose audio**。通过文件选择器选择支持的单声道或立体声文件；可解码的文件格式取决于构建版本和平台。支持源文件采样率 **8-384 kHz**。单声道素材会复制到两个声道。

![选择文件后，Sample 会预览所选片段，并启用 Import and Freeze。Normalize 为可选项，初始状态为关闭。](images/12-granular-import.png)

录音最长为 **1.02175 秒**，即 **32 kHz 下的 32,696 个立体声帧**。这一上限不会随宿主采样率提高而增长。对于较长的源文件，可移动起始位置控件或输入起始时间，再检查所选片段的波形。波形只提供导入区段的视觉预览，并不是独立的试听播放按钮。

**Normalize to -1 dBFS** 默认关闭。启用后，会在采样率转换后按左右声道共用的峰值进行归一化，且不改变两者的相对平衡。保持关闭可保留振幅；若源峰值超出目标格式的范围，可能发生削波。片段准备好后，点击 **Import and Freeze**。Fire 只替换当前模块的录音，并启用 Freeze；播放期间会对湿声进行短暂过渡。

一次导入对应一步 Undo。撤销可以恢复此前的冻结录音及其设置。如果模块先前处于实时录音状态，撤销会恢复实时模式，但无法重建之前的滚动音频。导入的录音会直接嵌入，因此源文件不必继续保留在磁盘上。关闭编辑器或替换目标模块时，会取消尚未完成的导入，而不会将其改送至其他位置。

### 导出冻结素材

![捕获的实时录音可从 Sample 导出。在选择导入文件之前，Start、Normalize 和 Import and Freeze 仍不可用。](images/12-granular-sample.png)

存在有效的冻结录音时，打开 Sample 并点击 **Export frozen WAV**。选择目标位置；如果文件已存在，确认是否覆盖。Fire 会在目标位置选择器打开前取得录音快照，因此之后的参数变化不会改变此次导出内容。

WAV 按时间顺序包含 **立体声、16-bit / 32 kHz** 音频。它导出的是录音本身，**不包含**粒子调度、Pitch、Feedback、Reverb 或 Mix 的处理结果，导出时也不会额外归一化。若要保存处理后的粒子演奏，应在宿主中录制或渲染 Fire 的输出。较短的捕获录音只导出已有帧，不会人为扩展到完整容量。

Clouds 的其他时间拉伸、循环延迟和频谱模式并未包含在内，硬件触发输入和其他低保真模式也不在其中。利用 Freeze 配合调制，即可在当前提供的普通粒子模式中创造丰富变化。

## 16. 调制路由与宏

Fire 最多提供 16 个 LFO、四个包络跟随器、四个宏和四个 MIDI CC 调制源。调制矩阵将这些调制源连接到支持调制的目标控件。多个路由可以共同控制同一个目标；各路贡献相加后，最终结果会限制在该参数的有效范围内。

### 第一次分配 LFO

1. 打开 **Mod Forge**，在左侧栏中选择一个 LFO。如果列表为空，使用 **+** 添加。
2. 设置 Rate。启用 **BPM** 可使用跟随宿主速度的节拍时值；关闭时则按独立速度运行。
3. 点击 **Assign**，再点击 Band Lab 或 Master Lab 中的目标控件。也可以右键点击支持调制的旋钮，选择 **Add modulation source** 下的调制源。
4. 打开网格图标对应的 Matrix 控件，检查路由。调整 Depth，并选择 **Bi** 或 **Uni**。
5. 观察旋钮周围以调制源颜色显示的范围。基准刻线表示基础值，移动的空心圆点表示调制后的值。

矩阵中的 **Add routing** 用于创建另一条连接。每一行包括 Source、Destination、Depth、极性、启用/旁通和删除控件。旁通路由会保留它的设置，但停止其调制作用。右键点击已分配调制的旋钮，可选择 **Edit modulation in matrix** 或 **Clear all modulation**。点击代表多个路由或自定义范围的调制源徽标，可打开相应路由。

点击 Destination 可打开支持搜索的目标选择器。你可以按控件、模块、参数 ID 或频段搜索，并按作用范围或模块筛选。**Active chain** 突出显示当前链中的模块；**All targets** 则包含尚未添加的模块和未启用的频段。暂不可用的分配可以保留，但查看它不会自动插入或启用对应模块。**Show control** 会打开目标页面并聚焦相应旋钮。在选择器中，向下方向键可将焦点从搜索框移到结果，Enter 选择，Escape 取消。

| 字段 | 含义 |
| --- | --- |
| **Depth** | -100% 至 +100%；按比例缩放映射的偏移量。 |
| **Bi** | 标准双极性偏移，为目标归一化范围的 -50% 至 +50%。 |
| **Uni** | 标准单极性偏移，为 0% 至 +100%。 |
| **From / To** | 相对于旋钮基础值的自定义偏移，两者均为 -100% 至 +100%。编辑任一值即启用自定义范围。 |
| **Curve** | Linear、Ease in、Ease out 或 S curve；在两个端点之间插值前应用该曲线。 |
| **Depth via** | 可选择 Fixed，或选择一个宏，将路由的 Depth 从零缩放到完整强度。 |

偏移量以参数的**归一化范围**为单位，并不一定对应线性变化的 Hz 或 dB 数值。例如，当 From 为 -20%、To 为 +30%、Depth 为 100% 时，调制范围就是相对于旋钮基础值的这两个偏移。Depth 为 50% 时，两个偏移都会减半。点击 Bi/Uni 会恢复其标准端点。Depth via 宏用于缩放路由强度，不会替换原来的调制源。需将该宏设为大于零，路由才会产生可听见的作用。

调制源控件不能递归调制自身。路由模式和模块结构分配不属于普通的内部调制目标。若要动态改变并联平衡，应调制 Blend，而不是路由模式。

## 17. LFO 波形与播放方式

![Mod Forge 中可直接编辑的三角形波形。在侧栏选择 LFO，编辑曲线，再分配目标。](images/14-mod-forge-panel.png)

Fire 初始提供四个 LFO，最多允许 16 个。在可滚动的 LFO BANK 中选择需要编辑的源。删除一个调制源会清除它的路由，但不会重新编号其他源。重新使用空闲槽位时，波形和时序设置会从初始状态开始。所有 LFO 都可以删除；包络跟随器、宏和 MIDI CC 仍可使用。

编辑器提供 **Edit** 和 **Brush** 模式。在 Edit 模式下，双击空白处添加点，拖动点改变位置，双击点将其删除。第一个和最后一个点不能删除。拖动线段可调整曲线弯曲程度。按住 Shift 拖动可框选多个点；拖动选中的点会移动整组选区。在 macOS 上按住 Cmd，或在 Windows 上按住 Ctrl 拖动，可吸附到网格。X/Y 网格控件用于设置各方向的分格数。

右键点击编辑器可使用 **Select All**、**Clear**、**Copy**、**Paste**、**Invert Horizontally** 和 **Invert Vertically**。Clear 会恢复为默认直线形状。Brush 模式使用鼠标左键绘制所选的预设片段，可选 Saw Up、Saw Down、Sine Convex、Sine Concave、Square High 和 Square Low。

Rate 设置速度，BPM 选择是否同步，Smooth 使绘制的波形更平滑，Phase 偏移波形的读取位置。移动的高亮位置反映实际用于音频处理的相位。只要音频回调仍在运行，即使宿主停止播放，高亮仍可能继续移动；回调停止后，高亮会保持位置并逐渐淡出。

### 播放方式与可重复的随机变化

为当前选中的 LFO 点击 **Playback**。

| 设置 | 行为 |
| --- | --- |
| **Loop** | 按独立速度或宿主同步速度持续循环播放。 |
| **Retrigger** | 匹配的 MIDI Note On 或手动 Trigger 会重新启动周期，之后继续循环。 |
| **One-shot** | 每次触发播放一个周期，随后保持最终值。 |
| **Shape** | 读取绘制的波形；Smooth 对此模式有效。 |
| **Random Hold** | 在随机值之间阶梯式切换。 |
| **Random Glide** | 在随机值之间平滑插值。 |

Trigger Note 可选 0-127 或 **Any**，通道可选 1-16 或 **Omni**。Note Off 不会触发。**Trigger** 可以手动启动 Retrigger 或 One-shot，无需输入 MIDI。Seed 范围为 0-65535；相同的种子和触发序列可以复现相同的随机序列。每次触发都会推进随机序列，而不是总从相同的第一个值重新开始。

绘制的曲线和 Smooth 只影响 Shape。随机模式下的 One-shot 忽略 Phase：Hold 保持一个随机值，Glide 则完成一次过渡。Shape 的 One-shot 从 Phase 指定的位置开始，但仍播放完整的一个周期。播放设置和种子会随音色保存，手动 Trigger 操作本身不会保存。

![Playback 可设置 Loop/Retrigger/One-shot、Shape 或随机波形、MIDI 触发筛选条件以及随机种子。](images/17-lfo-playback.png)

## 18. 包络跟随器与外部侧链

打开 **Matrix  >  Envelopes / Macros**，再选择 **ENV 1-4**。每个检测器都有独立的输入、滤波器、Attack、Release 和 Sensitivity 设置。

![每个 ENV 都有独立的检测输入和滤波设置。示例中选中了 External sidechain；宿主还需实际将信号路由到该侧链输入。](images/16-envelopes-macros.png)

| 控件 | 范围 / 用途 |
| --- | --- |
| **Detector** | Main input、External sidechain 或 Band 1-4。 |
| **High Pass** | 20 Hz-20 kHz，有独立启用开关；默认 80 Hz，处于旁通状态。 |
| **Low Pass** | 20 Hz-20 kHz，有独立启用开关；默认 12 kHz，处于旁通状态。 |
| **Attack** | 0.1-500 ms；默认 10 ms。 |
| **Release** | 5-2,000 ms；默认 200 ms。 |
| **Sensitivity** | -24 至 +24 dB；默认 0 dB。 |
| **Hold to listen** | 按住时临时监听所选检测器经过滤波的信号。 |

主输入和频段输入均取自效果处理之前。频段检测器使用独立的 24 dB/oct 滤波，跟随当前分频边界，取样位置也在 Solo 和输出增益之前。未启用的频段或未连接的侧链会提供静音信号。立体声能量检测仍能响应左右声道极性相反的输入。检测器滤波器改变的是包络跟随器所检测的内容，不是处理声音的 EQ 控件。

若希望音色随演奏力度变化，可选择 Main input，设置较快的 Attack 和适中的 Release，再以较小的正向深度将该 ENV 路由到 Shape Mix 或 Drive。提高 Sensitivity，直到较轻的演奏也能产生合适的变化。调整 Release，使音符之间平滑恢复，然后细调 Depth，避免效果过强。

若要使用外部信号控制，在宿主中将另一条轨道路由到 Fire 的侧链输入，选择 **External sidechain**，再在矩阵中分配该 ENV。将负向深度的路由分配给合适的电平或 Mix 控件，可在侧链信号增强时压低该目标。具体路由方式取决于 DAW 和插件格式；仅选择 External sidechain 不会自动建立宿主连接。

用鼠标按住 **Listen**，或在该控件获得焦点时按住 Space/Return，可检查经过滤波的检测信号。松开后返回正常输出。隐藏或关闭面板也会结束监听。这是临时监听状态，不会保存，也不支持自动化。

第一个检测器在调制源菜单中可能显示为 **Envelope**，而控制标签使用 **ENV 1**。其余检测器都是独立调制源，不是 ENV 1 的副本。

## 19. MIDI 控制

打开 **Mod Forge  >  MIDI**。四个槽位各自可以监听指定通道或 Omni 上的 CC 0-127。选择 **Off** 可禁用该槽位。

1. 在宿主中，将控制器或轨道的 MIDI 路由到 Fire。
2. 点击某个槽位的 **Learn**，再移动所需的硬件控件。Fire 会记录它的 CC 编号和通道。再次点击 Learn 或关闭面板可取消学习。
3. 打开 Matrix，为目标选择对应的 **MIDI CC 1-4** 调制源。
4. 像设置 LFO 路由一样设置范围、曲线和深度。如果希望同一控制器在任意通道上都有效，使用 Omni。

![四个 MIDI CC 槽位可以手动配置，也可以通过 Learn 学习。宿主将 MIDI 传入 Fire 后，它们即可作为调制源使用。](images/18-midi-controls.png)

MIDI CC 配置会保存，传入的控制器位置则属于实时演奏数据。宿主必须将 MIDI 传入 Fire。Fire 保留了 AU 效果器身份，因此某些 AU 宿主无法向它发送 MIDI。在宿主支持效果器 MIDI 路由时，可以使用 VST3 或 CLAP；也可以使用普通参数自动化。MIDI 音符可以触发 LFO，但不会将 Fire 变成合成器。

## 20. 实用声音设计示例

以下示例用于提供起点，并非 Factory 预设的参数规范。先将声源调至合适的监听电平，再平衡处理后的响度。编辑前先选择目标频段，并确认其模块开关已启用。

### 吉他：随演奏力度变化的轻度失真

1. 从单频段开始，将 Drive 放在 Shape 之前。
2. 选择 **Tweed Breakup**，先使用适中的 Drive，开启 Safe，关闭 Extreme。
3. 寻找基本音色时，让 Bias 和 Rectification 接近零。交替轻弹和重弹，同时调整 Drive。
4. 如果低音过度主导失真，在 Shape 之前添加 EQ；如果生成的音色过暗或过尖，则在 Shape 之后添加 EQ。
5. 添加 **Spring** Reverb，使用较小的 Mix；如果混响尾音使低频浑浊，提高 Low Cut。
6. 匹配处理前后的电平。Fire 的吉他风格音色属于失真处理级，不是完整的箱体/麦克风模拟器。

### 贝斯：保留低频分量，增加清晰度

1. 对声源分频，让低频基音区域可以保持相对干净；用听感决定分频点。
2. 选择高频段，尝试 **Warm Triode**、**Diode Overdrive** 或 **Transformer**。
3. 增加 Drive，直到音符在小扬声器上也足够清晰；如果结果太刺耳，降低该频段的 Mix。
4. 如果高频音符的动态变化过大，使用适中的 Compressor 压缩比。
5. 关闭 Solo，在完整混音和单声道下检查。低频段避免使用极端的 Width 设置。

### 人声：增加厚度，同时避免持续刺耳

1. 使用单频段，或对指定频段进行轻微处理。添加 **Class A Console** 或 Warm Triode，并使用较低的 Drive。
2. 在 Shape 之后放置 EQ，通过听感找到刺耳频率，再在该处创建 Bell。
3. 启用该点的 Dynamic 控件，选择负向 Range，并降低 Threshold，直到只有较强的乐句需要衰减。
4. 添加 **Plate** Reverb，设置足够的 Pre-delay，让字头与尾音分离，同时使用 Low Cut 保持清晰。
5. 在响度匹配后进行对比，确认辅音仍然自然。

要抑制刺耳的人声共振，在问题频率处使用 Bell，基础 Gain 保持在 0 dB 附近，设置负向 Range，再降低 Threshold，直到响亮的音节触发衰减。先从较小的 Range 开始：通常只需偶尔控制几 dB，而不是持续进行大幅削减。

### 鼓：并联增强力度

1. 打开处理链的 Routing，选择 **Parallel A/B**。
2. 将 A 分支上已有的全部处理模块移走或删除，使其成为直通信号路径，再将 **OTT** 放到 B 分支，按需加入 Shape。
3. 使用适中的 OTT Depth，调整 Up / Up Thresh 以突出较轻的击打，调整 Down / Down Thresh 以控制峰值。
4. 将 Blend 从接近 A 端的位置开始调节，逐渐加入 B，直到节奏更饱满，同时保留干声的起音。
5. 尝试在 B 上使用 Lo-Fi 增加质感，再以相近的输出电平对比完整循环。

### 铺底音色与过渡：冻结的粒子云

1. 添加 Granular，向其输入持续和弦，或使用 **Sample** 导入合适的片段。
2. 启用 Freeze，将 Density 调离中心，并选择较平滑的 Texture。
3. 降低 Pitch 可得到更暗的铺底音色，提高则可获得更轻盈的声部；调整 Position，避开不需要的咔嗒声或不稳定片段。
4. 为 Position 或 Size 添加缓慢调制，并控制好调制范围。
5. 在后面添加 Hall Reverb，或将其放在同一并联分支，再用 Blend 逐渐引入这一层质感。
6. 将预设连同冻结录音一起保存。只有需要原始素材时才导出原始 WAV；若要保留完整且持续变化的效果，应在宿主中渲染。

### 演奏宏：同时塑造多个参数

为每个目标分别添加一条路由，并为它们选择同一个 Macro 调制源。分别设置深度和极性：例如，一个宏可以提高失真 Drive、降低 Output，同时轻微增加混响 Mix。从零开始，边听边缓慢转动。明确用途后，在主页面为宏重命名。四个宏均为可由宿主自动化的 0-100% 控件，数值变化带有短暂的平滑过渡。名称、数值和路由都会随音色、A/B 和工程保存。

## 21. 设置、性能与故障排查

选择 **Menu  >  Skin  >  Modern / Vintage / Paper / Ink**，或使用 Settings 中的四个外观按钮。切换不会改变声音或撤销历史。Modern 采用石墨色和铝质风格；Vintage 使用木质元素和实体控件；Paper 与 Ink 使用精细线条图形，分别搭配浅色和深色配色。皮肤是本地偏好设置；新实例会使用已保存的选择，已打开的实例保留各自的皮肤。从编辑器角落拖动可调整尺寸，界面会在支持的尺寸范围内保持 2:1 布局。

![Settings 提供外观选择和本地复制诊断信息功能。本图来自文档测试宿主；你的 DAW 和音频配置会有所不同。](images/22-settings.png)

**Menu  >  Settings** 显示版本、修订/构建信息、格式、架构、宿主、采样率、缓冲区大小、通道、延迟和 HQ 状态。**Copy diagnostics** 会刷新信息并将其复制到本地剪贴板，方便粘贴到问题报告中。插件不会自动发送这些内容。Settings 还提供 **Auto-check for updates on startup**；菜单中另有 **Check for New Version**。

| 现象 | 检查方法 |
| --- | --- |
| 宿主中找不到 Fire | 安装宿主支持的格式，重启或重新扫描，并检查宿主的验证结果或禁用插件列表。在 macOS 上，AU 和 VST3 是独立的插件包。 |
| 仍然显示旧版本 | 替换后重启宿主。检查 Settings 中已加载的版本/修订信息，以及宿主加载的格式和路径；电脑上可能同时存在多个安装副本。 |
| 没有声音 | 确认音频已到达轨道、乐器位于 Fire 之前，且宿主路由和输出已启用。检查频段的 Solo/开关、Output/Mix，以及极端的调制或冻结粒子设置。 |
| Side 视图为空 | 单声道或左右完全相同的信号没有 Side 内容。选择 Stereo 查看合并能量。 |
| 图表停止或看起来为空 | 确认音频回调仍在运行、相关视图处于可见状态，并已恢复频谱显示。隐藏视图或关闭编辑器时，图形有意暂停采集；音频处理仍会继续。 |
| 路由没有效果 | 检查路由启用开关、调制源是否存在、Depth、目标是否可用，以及 Depth via 宏是否为零。外部 ENV 需要实际的侧链信号。 |
| MIDI Learn 没有反应 | 检查宿主 MIDI 路由、格式支持、通道以及实际发出的消息类型。Learn 需要的是 MIDI CC。 |
| 编辑 LFO 曲线没有效果 | 检查 Playback 中的 Wave 模式。Random Hold/Glide 使用随机生成器，不读取已保存的曲线或 Smooth。 |
| 无法粘贴 | 目标必须有兼容的空闲槽位，并能保留源模块的表示方式；查看提示中的具体原因。合适时可尝试仅复制设置。 |
| Match 显示 Play audio 或 LIMIT | 播放具有代表性且输入/输出电平可用的片段；其最大补偿为 ±18 dB。 |
| CPU 占用升高 | 对同一片段关闭 HQ 进行比较，减少未必需要的高负载效果实例，并关闭或折叠分析视图。确认宿主缓冲区大小适合当前工程。 |

HQ 对 Shape 处理使用 4 倍过采样，也包括新增 Shape 模块。其开销取决于音色和启用的处理引擎数量；磁带等非线性模型可能比简单的数字波形更耗资源。不存在适用于所有电脑、采样率、缓冲区大小和预设的统一 CPU 百分比。应在相同条件下比较，并在听感收益值得时保留 HQ。折叠分析视图会减少图形处理工作，但不会关闭音频效果，也不会冻结延迟或混响尾音。

提交可复现的问题报告时，请附上诊断信息、预设或最小处理链、操作顺序、预期结果和实际现象。说明问题是否也会出现在新建实例中，以及重新打开工程后是否仍然存在。

| Modulation source / 调制源 | LFO、包络检测器、宏或 MIDI CC 信号。 |
| Depth / 深度 | 一个调制源对目标的作用量及其正负方向。 |
| Normalized range / 归一化范围 | 控件内部的 0-1 位置，不一定与 Hz、ms 或 dB 呈线性关系。 |
| A/B sound memories / A/B 音色记忆 | 在顶部栏中选择的两份完整对比音色。 |
| Parallel branches A/B / 并联分支 A/B | 一个 Band 或 Master 处理链内同时运行的两条路径。 |
| Mid / Side / 中置与侧向 | 立体声音频的中置分量 `(L+R)/2` 与差分分量 `(L-R)/2`。 |
| Freeze / 冻结 | 保持 Granular 录音内容，同时让粒子继续播放。 |
| Raw frozen WAV / 原始冻结 WAV | 保存的录音素材，不包含后续粒子演变或效果处理。 |
| HQ | 以更高采样率运行的 Shape 处理路径；不会增加 Granular 的录音容量。 |
| Latency compensation / 延迟补偿 | 宿主将插件延迟与其他信号路径对齐的机制。 |

### 关于本版本与支持

本手册介绍的是 2.1.0 开发版的操作方式，不代表早期发行版包含相同功能。新预设可能无法在旧版 Fire 中加载。将正式制作工程迁移到其他版本前，请保留重要原始预设和工程的副本。

原生模块与独立新增模块有时具有不同的参数范围或兼容行为。本手册会在影响操作的位置说明这些差异。模拟风格音色属于建模和创意处理器，不保证精确复刻某一具体型号的硬件。Fire 不包含吉他箱体/麦克风模拟器。
