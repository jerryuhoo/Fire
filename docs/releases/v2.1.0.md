Fire 2.1.0 adds more control over modulation, routing and sample-based sound design, and corrects Windows CLAP editor scaling.

## What's new

- **Four independent envelope followers** with main-input, per-band and external-sidechain sources, detector filters and momentary listening.
- **Expanded modulation:** multiple sources per target, adjustable ranges and curves, macro-controlled depth, four MIDI CC sources, note-triggered/one-shot LFOs and deterministic random shapes.
- **Flexible chains:** Stereo, Mid or Side processing; latency-aligned serial/parallel routing; module copy/duplicate/paste; and portable `.firechain` presets.
- **Dynamic EQ:** per-point dynamics for Bell and Shelf filters, with live gain-change feedback.
- **Granular audio import/export:** select the imported region, preview its waveform, normalize if needed, and export frozen audio as WAV.
- **Preset workflow:** parameter locks, editable tags and notes, recent sounds and persistent browser state.
- **Interface fixes:** correct Windows CLAP scaling at fractional display settings such as 125%, consistent Band/Master/inserted OTT displays, and safer dialog lifetime handling.
- **Six illustrated manuals**, including the new Traditional Chinese edition.

Fire includes 236 factory presets in 11 collections and four interchangeable skins: Modern, Vintage, Paper and Ink.

## Compatibility and validation

Existing automation parameter identities are preserved. Older sounds retain
their compatibility behavior where applicable; presets using new 2.1 features
may not load in older Fire versions. Keep copies of important projects and presets.

Release packages pass the platform test suites, strictness-10 VST3 validation,
macOS AU validation and CLAP binary load/audio/state checks. Windows CLAP scaling
tests cover 100%, 125%, 150% and 200%. Report host-specific problems through the
[issue tracker](https://github.com/jerryuhoo/Fire/issues), with **Settings > Copy diagnostics**
and reproducible steps.
